Picture: A very patient pen-friend who has read millions of letters. You write to them in English, Hindi or Hinglish; they understand what you mean, sort your letters into piles, answer questions, translate, and even write back. Natural Language Processing (NLP) is teaching computers to be that pen-friend.

Good to know

  • Language is hard for computers: the same word has many meanings ('bank'), the same meaning has many words ('refund', 'money back'), and people make typos, mix languages and joke.
  • Two big eras: classic NLP (rules, counting words, small statistical models) and neural NLP (embeddings, Transformers, large language models). Both are used today: classic methods are cheap, fast and easy to explain.

5 Text Is Just Numbers: Characters, Unicode, UTF-8

Picture: A secret code book: every letter, Hindi akshar and emoji has a number (its code point). UTF-8 is the way those numbers are packed into bytes for storage, like packing toys into boxes of different sizes.
Characters, bytes and normalisation (run for real)
# Text is just numbers: characters -> Unicode code points -> bytes (UTF-8)
import unicodedata
for s in ["cat", "café", "नमस्ते", "😀", "Ｈｅｌｌｏ"]:
    print(f"{s!r:12} chars={len(s):2}  utf8 bytes={len(s.encode('utf-8')):2}  code points={[hex(ord(c)) for c in s][:6]}")
a, b = "café", "café"                       # same look, different code points
print("looks same, equal?", a == b, "| after NFC normalisation:", unicodedata.normalize("NFC", a) == unicodedata.normalize("NFC", b))
print("NFKC turns full-width 'Ｈｅｌｌｏ' into", unicodedata.normalize("NFKC", "Ｈｅｌｌｏ"))
print("casefold:", "Straße".lower(), "vs", "Straße".casefold())

# 'नमस्ते'     chars= 6  utf8 bytes=18  code points=['0x928', '0x92e', '0x938', '0x94d', '0x924', '0x947']

Good to know

  • One Hindi word 'नमस्ते' is 6 code points but 18 bytes. One emoji is 1 code point and 4 bytes. Limits written in 'characters' and limits in 'bytes' are different things.
  • Normalisation (NFC/NFKC) makes text that looks the same also be the same: 'café' typed two ways, or full-width letters from some keyboards.
  • Use casefold() rather than lower() for case-insensitive matching in many languages.

6 Cleaning Text with Regular Expressions

Picture: Sweeping a room before guests come: remove dust (extra spaces), hide valuables (phone numbers, e-mails), and put labels on boxes (<URL>).
Cleaning and sentence splitting (run for real)
# Cleaning text with regular expressions (keep a copy of the raw text: cleaning loses information!)
import re
raw = "Call me at +91-98765-43210 or mail ASHA.K@example.com!!! Visit https://shop.example.com/sale?id=7 :) Price: Rs. 1,299"
t = raw
t = re.sub(r"https?://\S+", " <URL> ", t)
t = re.sub(r"\S+@\S+\.\w+", " <EMAIL> ", t)
t = re.sub(r"\+?\d[\d-]{8,}\d", " <PHONE> ", t)
t = re.sub(r"\d[\d,]*", " <NUM> ", t)
t = re.sub(r"([!?.])\1+", r"\1", t)              # '!!!' -> '!'
t = re.sub(r"\s+", " ", t).strip().lower()
print("raw  :", raw)
print("clean:", t)
text = "Dr. Rao met Mr. Iyer at 5 p.m. in Pune. They talked. It rained!"
naive = [s for s in re.split(r"(?<=[.!?])\s+", text)]
print("naive sentence split  :", naive)
safe = re.split(r"(?<!\bDr\.)(?<!\bMr\.)(?<!p\.m\.)(?<=[.!?])\s+(?=[A-Z])", text)   # do not split after known abbreviations
print("with abbreviation list:", safe)

# ----- Output (real run) -----
# raw  : Call me at +91-98765-43210 or mail ASHA.K@example.com!!! Visit https://shop.example.com/sale?id=7 :) Price: Rs. 1,299
# clean: call me at <phone> or mail <email> ! visit <url> :) price: rs. <num>
# naive sentence split  : ['Dr.', 'Rao met Mr.', 'Iyer at 5 p.m.', 'in Pune.', 'They talked.', 'It rained!']
# with abbreviation list: ['Dr. Rao met Mr. Iyer at 5 p.m. in Pune.', 'They talked.', 'It rained!']

Good to know

  • Replacing personal data with placeholders (<PHONE>, <EMAIL>) protects privacy and stops the model from memorising them.
  • Sentence splitting is harder than splitting on full stops: 'Dr.', 'p.m.' and decimals break naive rules (the naive split made 6 'sentences' out of 3). The improved rule works here only because it lists these exact abbreviations; real text has thousands, so libraries such as spaCy use trained models.
  • Do not over-clean for modern models: punctuation, case and emojis carry meaning (':)' is a sentiment signal).

# Word tokenization, stop words, and a crude stemmer (to see why lemmatization exists)

text = "The children aren't playing; they're studying NLP's basics in 2026!"
print("split on spaces :", text.split())
print("regex word+punct:", re.findall(r"\w+(?:'\w+)?|[^\w\s]", text))
STOP = {"the", "a", "an", "in", "on", "they're", "are", "is", "of", "to", "and"}
words = [w.lower() for w in re.findall(r"\w+(?:'\w+)?", text)]
print("without stop words:", [w for w in words if w not in STOP])
def stem(w):                                      # tiny suffix stripper (NOT the real Porter stemmer)
    for suf in ("ing", "ies", "es", "ed", "s"):
        if w.endswith(suf) and len(w) - len(suf) >= 3:
            return w[: -len(suf)] + ("y" if suf == "ies" else "")
    return w
for w in ["playing", "studies", "studied", "boxes", "news", "running", "better", "children"]:
    print(f"  stem({w!r}) = {stem(w)!r}")
LEMMA = {"children": "child", "better": "good", "ran": "run", "running": "run", "studies": "study", "mice": "mouse"}
print("lemma (dictionary) ->", {w: LEMMA.get(w, w) for w in ["children", "better", "running", "mice"]})

9 Sub-word Tokens: Byte-Pair Encoding from Scratch

Picture: Making words from syllable stickers. If 'est' appears again and again, you print a single 'est' sticker. After many such merges, common words become one sticker and rare words are built from a few.
BPE merges on a 4-word corpus (run for real)
# Byte-Pair Encoding (BPE) from scratch: how GPT-style tokenizers learn sub-words
from collections import Counter
corpus = {"low": 5, "lower": 2, "newest": 6, "widest": 3}     # word -> frequency
vocab = {" ".join(w) + " </w>": f for w, f in corpus.items()}
def pair_counts(v):
    c = Counter()
    for word, f in v.items():
        s = word.split()
        for a, b in zip(s, s[1:]):
            c[a, b] += f
    return c
merges = []
for step in range(8):
    pc = pair_counts(vocab)
    best = max(pc, key=pc.get)
    merges.append(best)
    vocab = {w.replace(" ".join(best), "".join(best)): f for w, f in vocab.items()}
    print(f"merge {step + 1}: {best[0]!r} + {best[1]!r} (seen {pc[best]}x)")
print("final vocabulary:", list(vocab))
def encode(word):
    s = list(word) + ["</w>"]
    for a, b in merges:
        i = 0
        while i < len(s) - 1:
            if s[i] == a and s[i + 1] == b:
                s[i:i + 2] = [a + b]
            else:
                i += 1
    return s
for w in ["lowest", "newer", "wider", "slow"]:
    print(f"encode({w!r}) -> {encode(w)}")

# merge 5: 'lo' + 'w' (seen 7x)
# merge 6: 'n' + 'e' (seen 6x)

Good to know

  • The unseen word 'lowest' was still encoded as low + est: sub-words mean no unknown words.
  • GPT-style models use byte-level BPE; BERT uses WordPiece; T5 and many multilingual models use SentencePiece (unigram or BPE). All share the idea: frequent pieces get their own token.
  • Vocabulary size is a trade-off: bigger vocabulary = shorter sequences but a bigger embedding table.

11 Edit Distance and Spelling Correction

Picture: Counting the fewest moves to turn one word into another, like a word-ladder game: change a letter, add one, or remove one.
Levenshtein distance + a tiny spell checker (run for real)
# Levenshtein edit distance (dynamic programming) and a tiny spelling corrector
def lev(a, b):
    d = list(range(len(b) + 1))
    for i, ca in enumerate(a, 1):
        prev, d[0] = d[0], i
        for j, cb in enumerate(b, 1):
            prev, d[j] = d[j], min(d[j] + 1, d[j - 1] + 1, prev + (ca != cb))
    return d[-1]
for a, b in [("kitten", "sitting"), ("flaw", "lawn"), ("intention", "execution")]:
    print(f"lev({a!r}, {b!r}) = {lev(a, b)}")
VOCAB = {"delivery": 50, "refund": 40, "return": 35, "password": 30, "order": 60, "warranty": 10, "invoice": 15}
def correct(w):
    return min(VOCAB, key=lambda v: (lev(w, v), -VOCAB[v]))
for typo in ["delivry", "refnd", "pasword", "ordr", "invoise", "retrun"]:
    print(f"{typo:8} -> {correct(typo)}")

13 n-gram Language Models and Perplexity

Picture: Guessing the next word in a nursery rhyme from the last word you heard. After 'the', you have heard 'cat' and 'dog' most often, so you guess one of them.
A bigram model with add-k smoothing (run for real)
# A bigram language model with add-k smoothing, perplexity, and sampling
import math, random
from collections import Counter, defaultdict
from nlpdata import STORY
sents = [s.strip().split() for s in STORY.split(".") if s.strip()]
train = sents[: int(len(sents) * 0.8)]
uni, bi = Counter(), defaultdict(Counter)
for s in train:
    toks = ["<s>"] + s + ["</s>"]
    uni.update(toks)
    for a, b in zip(toks, toks[1:]):
        bi[a][b] += 1
V = len(uni)
def p(b, a, k=0.1):
    return (bi[a][b] + k) / (sum(bi[a].values()) + k * V)
def perplexity(words):
    toks = ["<s>"] + words + ["</s>"]
    lp = sum(math.log(p(b, a)) for a, b in zip(toks, toks[1:]))
    return math.exp(-lp / (len(toks) - 1))
for s in ["the cat sat on the mat", "the dog ate the fish", "mat the on sat cat the", "the bird sang a song"]:
    print(f"perplexity({s!r:28}) = {perplexity(s.split()):6.2f}")
random.seed(3)
for _ in range(3):
    w, out = "<s>", []
    while len(out) < 12:
        nxt = random.choices(list(bi[w]), weights=list(bi[w].values()))[0]
        if nxt == "</s>": break
        out.append(nxt); w = nxt
    print("sampled:", " ".join(out))
print("next-word table after 'the':", bi["the"].most_common(5))

16 Part-of-Speech Tagging with an HMM and Viterbi

Picture: Guessing each word's job in a sentence (noun, verb ...) using two hints: what this word usually is, and what usually comes after the previous job. After 'the' comes a noun or adjective much more often than a verb.
Hidden Markov Model tagger trained on 16 sentences (run for real)
# Part-of-speech tagging with a Hidden Markov Model and the Viterbi algorithm (from scratch)
import math
from collections import Counter, defaultdict
from nlpdata import POS, POS_TEST
def parse(lines): return [[tuple(tok.rsplit("/", 1)) for tok in l.split()] for l in lines]
train, test = parse(POS), parse(POS_TEST)
trans, emit, tagc = defaultdict(Counter), defaultdict(Counter), Counter()
for s in train:
    prev = "<s>"
    for w, t in s:
        trans[prev][t] += 1; emit[t][w] += 1; tagc[t] += 1; prev = t
TAGS = list(tagc)
def lp_trans(a, b): return math.log((trans[a][b] + 0.1) / (sum(trans[a].values()) + 0.1 * len(TAGS)))
def lp_emit(t, w): return math.log((emit[t][w] + 0.01) / (tagc[t] + 0.01 * 1000))
def viterbi(words):
    V = [{t: (lp_trans("<s>", t) + lp_emit(t, words[0]), None) for t in TAGS}]
    for w in words[1:]:
        V.append({t: max((V[-1][p][0] + lp_trans(p, t) + lp_emit(t, w), p) for p in TAGS) for t in TAGS})
    t = max(V[-1], key=lambda k: V[-1][k][0]); path = [t]
    for col in reversed(V[1:]):
        t = col[t][1]; path.append(t)
    return path[::-1]
ok = n = 0
for s in test:
    words, gold = [w for w, _ in s], [t for _, t in s]
    pred = viterbi(words)
    ok += sum(a == b for a, b in zip(pred, gold)); n += len(gold)
    print(" ".join(f"{w}/{p}" + ("" if p == g else f"(gold {g})") for w, p, g in zip(words, pred, gold)))
print(f"tag accuracy on {len(test)} unseen sentences: {ok}/{n} = {ok / n:.2f}")
print("unknown word test:", viterbi("the purple cat jumps".split()), "<- 'purple'/'jumps' never seen; context decides")

# a/DET girl/NOUN sings/VERB loudly/ADV
# the/DET man/NOUN reads/VERB a/DET red/ADJ book/NOUN

  • Two tables are learned by counting: transition P(tag | previous tag) and emission P(word | tag). Viterbi finds the best tag sequence with dynamic programming.

17 Named Entity Recognition (NER)

Picture: Using highlighter pens on a newspaper: pink for people, green for companies, yellow for places, blue for dates and money.
Gazetteer + regex NER, BIO tags, entity F1 (run for real)
# Named Entity Recognition with a gazetteer + rules, BIO tags, and entity-level F1
import re
GAZ = {"PERSON": ["Asha Rao", "Ravi Kumar", "Meera"], "ORG": ["Infosys", "Tata Motors", "ISRO"], "LOC": ["Pune", "New Delhi", "Bengaluru"]}
def ner(text):
    ents = []
    for label, names in GAZ.items():
        for n in names:
            for m in re.finditer(r"\b" + re.escape(n) + r"\b", text):
                ents.append((m.start(), m.end(), label))
    for m in re.finditer(r"\b\d{1,2} (January|February|March|April|May|June|July|August|September|October|November|December) \d{4}\b", text):
        ents.append((m.start(), m.end(), "DATE"))
    for m in re.finditer(r"(?:Rs\.?|₹)\s?[\d,]+", text):
        ents.append((m.start(), m.end(), "MONEY"))
    return sorted(ents)
def bio(text, ents):
    tags = []
    for m in re.finditer(r"\S+", text):
        lab = "O"
        for s, e, l in ents:
            if s <= m.start() < e: lab = ("B-" if m.start() == s else "I-") + l
        tags.append(f"{m.group()}/{lab}")
    return " ".join(tags)
text = "Asha Rao joined Tata Motors in Pune on 3 March 2026 with a salary of Rs. 12,00,000"
ents = ner(text)
print([(text[s:e], l) for s, e, l in ents])
print(bio(text, ents))
gold = [("Asha Rao", "PERSON"), ("Ravi", "PERSON"), ("ISRO", "ORG"), ("Bengaluru", "LOC"), ("Pune", "LOC")]
t2 = "Asha Rao and Ravi visited ISRO in Bengaluru, then flew back to Pune."
pred = [(t2[s:e], l) for s, e, l in ner(t2)]
tp = len(set(pred) & set(gold)); p, r = tp / len(pred), tp / len(gold)
print("predicted:", pred)
print(f"entity precision {p:.2f} recall {r:.2f} F1 {2 * p * r / (p + r):.2f}  <- 'Ravi' alone is not in the list: rules miss it")

19 Word Vectors: Meaning from Neighbours

# Word vectors from counting: co-occurrence -> PPMI -> SVD (the idea behind word2vec/GloVe, at toy scale)
import numpy as np
from collections import Counter
from nlpdata import STORY, REVIEWS
text = (STORY + " " + " ".join(t for t, _ in REVIEWS)).lower().replace(".", " ").replace(",", " ")
words = text.split()
vocab = [w for w, c in Counter(words).items() if c >= 3]
idx = {w: i for i, w in enumerate(vocab)}
C = np.zeros((len(vocab), len(vocab)))
for i, w in enumerate(words):
    if w not in idx: continue
    for j in range(max(0, i - 2), min(len(words), i + 3)):
        if j != i and words[j] in idx:
            C[idx[w], idx[words[j]]] += 1
total = C.sum(); pw = C.sum(1, keepdims=True) / total; pc = C.sum(0, keepdims=True) / total
with np.errstate(divide="ignore", invalid="ignore"):
    ppmi = np.maximum(np.log((C / total) / (pw * pc)), 0)
ppmi = np.nan_to_num(ppmi)
U, S_, _ = np.linalg.svd(ppmi)
E = U[:, :20] * S_[:20]
E /= np.linalg.norm(E, axis=1, keepdims=True) + 1e-9
print("vocabulary size:", len(vocab), "| vector size: 20")
for w in ["cat", "dog", "sat", "mat", "the"]:
    sims = E @ E[idx[w]]
    near = [vocab[k] for k in np.argsort(-sims)[1:6]]
    print(f"nearest to {w!r:6}: {near}")
print("note: tiny corpus -> neighbours mix meaning and grammar; real embeddings need millions of words")

# An LSTM classifier in PyTorch vs logistic regression on the same 60 reviews (5-fold, same splits)

from sklearn.model_selection import StratifiedKFold
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression

torch.manual_seed(0); np.random.seed(0)

tok = lambda s: re.findall(r"[a-z']+", s)
class LSTMClf(nn.Module):
    def __init__(self, V, d=32):
        super().__init__(); self.emb = nn.Embedding(V, d, padding_idx=0); self.lstm = nn.LSTM(d, d, batch_first=True); self.out = nn.Linear(d, 2)
    def forward(self, x):
        h, _ = self.lstm(self.emb(x)); lengths = (x != 0).sum(1) - 1
        return self.out(h[torch.arange(len(x)), lengths])            # last real token
def encode(seqs, vocab, L=14):
    X = np.zeros((len(seqs), L), dtype=np.int64)
    for i, s in enumerate(seqs):
        ids = [vocab.get(w, 1) for w in tok(s)][:L]; X[i, :len(ids)] = ids
    return torch.tensor(X)

23 Attention, Step by Step (Scaled Dot-Product)

Picture: A classroom where every student (token) asks a question (query), every student wears a name badge (key), and holds a note (value). Each student listens most to classmates whose badge matches their question, and mixes their notes.

# Scaled dot-product attention from scratch (NumPy), with a causal mask
import numpy as np
np.set_printoptions(precision=2, suppress=True)
words = ["the", "cat", "sat", "down"]
rng = np.random.default_rng(0)
X = rng.normal(size=(4, 8))                               # 4 tokens, 8-dim embeddings
Wq, Wk, Wv = (rng.normal(size=(8, 8)) / np.sqrt(8) for _ in range(3))
Q, K, V = X @ Wq, X @ Wk, X @ Wv
def softmax(z): z = z - z.max(-1, keepdims=True); e = np.exp(z); return e / e.sum(-1, keepdims=True)
scores = Q @ K.T / np.sqrt(K.shape[1])
A = softmax(scores)
print("attention weights (row = word looking, column = word looked at):")
print("        " + "  ".join(f"{w:>5}" for w in words))
for w, row in zip(words, A): print(f"{w:>6}  " + "  ".join(f"{v:5.2f}" for v in row))
mask = np.triu(np.ones((4, 4)), 1) * -1e9                 # GPT-style: no peeking at future words
Ac = softmax(scores + mask)
print("with causal mask:"); print(Ac)
out = A @ V
print("output shape:", out.shape, "| each row sums to 1:", np.allclose(A.sum(1), 1))

# Sinusoidal positional encodings (from 'Attention Is All You Need'): nearby positions look alike
import numpy as np
def pe(n, d):
    P = np.zeros((n, d)); pos = np.arange(n)[:, None]; i = np.arange(0, d, 2)
    P[:, 0::2] = np.sin(pos / 10000 ** (i / d)); P[:, 1::2] = np.cos(pos / 10000 ** (i / d)); return P

split = int(0.9 * len(data)); train, val = data[:split], data[split:]
B, T, D, H, L = 32, 48, 64, 4, 2
def batch(src):
    ix = torch.randint(len(src) - T - 1, (B,))
    return torch.stack([src[i:i + T] for i in ix]), torch.stack([src[i + 1:i + T + 1] for i in ix])
class Block(nn.Module):
    def __init__(self):
        super().__init__(); self.ln1, self.ln2 = nn.LayerNorm(D), nn.LayerNorm(D)
        self.att = nn.MultiheadAttention(D, H, batch_first=True); self.ff = nn.Sequential(nn.Linear(D, 4 * D), nn.GELU(), nn.Linear(4 * D, D))
    def forward(self, x):
        n = x.size(1); mask = torch.triu(torch.ones(n, n, dtype=torch.bool), 1)
        h = self.ln1(x); x = x + self.att(h, h, h, attn_mask=mask, need_weights=False)[0]
        return x + self.ff(self.ln2(x))
class TinyGPT(nn.Module):
    def __init__(self):
        super().__init__(); self.tok = nn.Embedding(len(chars), D); self.pos = nn.Embedding(T, D)
        self.blocks = nn.Sequential(*[Block() for _ in range(L)]); self.ln = nn.LayerNorm(D); self.head = nn.Linear(D, len(chars))
    def forward(self, idx):
        x = self.tok(idx) + self.pos(torch.arange(idx.size(1))); return self.head(self.ln(self.blocks(x)))
m = TinyGPT(); opt = torch.optim.AdamW(m.parameters(), lr=3e-3)

# Decoding strategies on one next-word probability table: greedy, temperature, top-k, top-p (nucleus)
import numpy as np
rng = np.random.default_rng(0)
words = np.array(["tea", "coffee", "water", "juice", "milk", "soda", "lassi", "rocket"])
logits = np.array([3.0, 2.6, 2.0, 1.2, 1.0, 0.3, 0.2, -2.0])        # model's scores after 'I would like a cup of'
def probs(l, t=1.0): z = np.exp((l - l.max()) / t); return z / z.sum()
print("greedy:", words[np.argmax(logits)])
for t in [0.5, 1.0, 2.0]:
    p = probs(logits, t); print(f"temperature {t}: " + ", ".join(f"{w}={v:.2f}" for w, v in zip(words, p)))
def sample(p, n=1000): c = rng.choice(len(p), n, p=p); return {str(words[i]): int((c == i).sum()) for i in np.argsort(-p)}
p = probs(logits)
k = 3; pk = np.where(np.argsort(np.argsort(-p)) < k, p, 0); pk /= pk.sum()
order = np.argsort(-p); cum = np.cumsum(p[order]); keep = order[: np.searchsorted(cum, 0.9) + 1]
pp = np.zeros_like(p); pp[keep] = p[keep]; pp /= pp.sum()
print("1000 samples, plain     :", sample(p))
print("1000 samples, top-k=3   :", sample(pk))
print("1000 samples, top-p=0.9 :", sample(pp), "| kept words:", [str(w) for w in words[keep]])

34 Summarization, Translation and Question Answering (and How They Are Scored)

BLEU and ROUGE from scratch (run for real)
# BLEU and ROUGE from scratch: how machine translation and summaries are scored
import math
from collections import Counter
def ngrams(t, n): return Counter(tuple(t[i:i + n]) for i in range(len(t) - n + 1))
def bleu(cand, ref, N=4):
    c, r = cand.split(), ref.split()
    ps = []
    for n in range(1, N + 1):
        cn, rn = ngrams(c, n), ngrams(r, n)
        overlap = sum(min(v, rn[k]) for k, v in cn.items())
        ps.append((overlap + 1) / (max(sum(cn.values()), 0) + 1))      # +1 smoothing
    bp = 1 if len(c) > len(r) else math.exp(1 - len(r) / max(len(c), 1))
    return bp * math.exp(sum(math.log(p) for p in ps) / N)
def rouge_n(cand, ref, n):
    cn, rn = ngrams(cand.split(), n), ngrams(ref.split(), n)
    ov = sum(min(v, rn[k]) for k, v in cn.items())
    rec, prec = ov / max(sum(rn.values()), 1), ov / max(sum(cn.values()), 1)
    return 0 if ov == 0 else 2 * prec * rec / (prec + rec)
def lcs(a, b):
    d = [[0] * (len(b) + 1) for _ in range(len(a) + 1)]
    for i in range(len(a)):
        for j in range(len(b)):
            d[i + 1][j + 1] = d[i][j] + 1 if a[i] == b[j] else max(d[i][j + 1], d[i + 1][j])
    return d[-1][-1]
ref = "the cat is sitting on the mat"
for cand in ["the cat is sitting on the mat", "the cat sits on the mat", "a feline rests on the rug", "mat the on sitting is cat the"]:
    l = lcs(cand.split(), ref.split())
    print(f"{cand!r:36} BLEU={bleu(cand, ref):.2f} ROUGE-1={rouge_n(cand, ref, 1):.2f} ROUGE-2={rouge_n(cand, ref, 2):.2f} ROUGE-L(recall)={l / len(ref.split()):.2f}")
print("the paraphrase 'a feline rests on the rug' is a fine answer but scores low: word-overlap metrics miss meaning")

the set of tokens a tokenizer knows

a vector of numbers representing a token or text

n-gram

how surprised a language model is (lower is better)

mechanism letting each token weigh all other tokens

adapting a pre-trained model to a task with labelled data

doing a task without task-specific training examples

fluent but unsupported or false generated text

45 Quick Quiz

Picture: Guess first, then open the answer.
1. Why can an English WordPiece tokenizer not read Hindi?

Its vocabulary has almost no Devanagari pieces, so Hindi becomes [UNK] tokens.

2. What does IDF reward?

Words that are rare across documents.

3. A shuffled sentence has very high perplexity. Why?

The language model finds those word orders very unlikely.

4. Why did the classic classifier on this page score below 0.5?

Sentiment words in the test folds were unseen and topic words pointed the wrong way.

5. What does the causal mask do?

Stops a token from attending to future tokens during generation.

6. What happens at higher temperature?

The probability distribution flattens: more surprising (and more wrong) words.

7. Which model family is best for sentence embeddings and classification?

Encoder (BERT-style) models.

8. Why is BLEU not enough?

It rewards word overlap, not meaning.

9. What is a cheap strong baseline for text classification?

TF-IDF + logistic regression.

10. How do you make LLM extraction safe for automation?

Structured output with a schema and validation.
