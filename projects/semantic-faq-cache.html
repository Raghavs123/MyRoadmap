2 How It Works: the Request Flow and the Architecture

A two-drawer filing cabinet with a careful clerk. Drawer 1: the exact same question asked before. Drawer 2: a question that means the same. The clerk refuses to file anything with a customer's phone number, and checks for "not" before handing out a saved answer.
Fig 2 — One request: the cache answers when it safely can, the LLM only on a miss.
  1. Personal data? Questions with an order id, phone, e-mail or name skip the cache completely and are never saved.
  2. L1 exact match: the same text after normalising (lower case, no punctuation): instant.
  3. Embed: the question becomes a 768-number vector of length 1 (cosine similarity = dot product).
  4. Top-3 nearest cached questions are found in the vector store.
  5. Decide: the first candidate with score ≥ T that passes the negation guard is a hit. A blocked best match may fall through to the next candidate.
  6. Miss: ask the LLM, return its answer, and save it if it is safe (no personal data, not a refusal). Answers about prices or policies get a 7-day TTL.
Fig 1 — Architecture: entry points on top, the bot in the middle, small replaceable parts below.

Each box is one file with one job. The parts talk through tiny interfaces (Embedder, VectorStore, LLMClient), so you can swap NumPy for FAISS or the stand-in LLM for Claude without touching the cache logic. This is called separation of concerns and dependency injection; factory.py is the single place that wires the real parts together.

📄 pyproject.toml 48 lines

The one modern file (PEP 621) that describes a Python project. Read it top to bottom:

  • [build-system]: which tool builds/installs the package (hatchling).
  • [project]: name, version, Python version (3.11+), and the dependencies every install needs: NumPy (maths), sentence-transformers (embeddings), Pydantic + pydantic-settings (data shapes and settings), FastAPI + Uvicorn (web API).
  • [project.optional-dependencies]: extras you add only when needed, e.g. pip install -e ".[faiss]" or ".[anthropic]". dev = tools for developers (pytest, ruff, httpx for API tests).
  • [project.scripts]: creates the terminal command faqcache that calls main() in cli.py.
  • [tool.hatch…]: our code lives in src/faqcache (the src layout: tests always import the installed package, never a stray local file).
  • [tool.ruff] and [tool.pytest.ini_options]: settings for the linter/formatter and the test runner.

6 Step 2: Settings in One Place (config.py)

A TV remote: all the buttons (threshold, model, which LLM…) are in one place, so you never open the TV to change the channel.

Every number the project might change lives here, read from environment variables that start with FAQ_ or from a .env file. The rest of the code asks Settings instead of hard-coding values.

📄 src/faqcache/config.py 72 lines

  • class Settings(BaseSettings): each attribute is one setting with a type and a default. pydantic-settings fills it from the environment: FAQ_THRESHOLD=0.9 sets threshold (thanks to env_prefix="FAQ_"), also from a .env file. extra="ignore" means unknown variables are ignored instead of crashing.
  • Literal["memory", "faiss"]: only these words are allowed; a typo fails at start-up, not later.
  • Field(0.83, ge=0.0, le=1.0): the threshold must be between 0 and 1.
  • volatile_ttl_s / default_ttl_s: little properties that turn days into seconds.
  • _empty_means_none: a validator so FAQ_LOG_PATH= (empty) means "no log file" instead of the folder "." (a real bug we found while testing the zip, see Part E).
  • get_settings() with @lru_cache: builds the settings once and reuses them (used by the API).
Full content of src/faqcache/config.py: copy it exactly
src/faqcache/config.py
"""All settings in one place (12-factor style: read from environment variables or a .env file).

Every variable starts with FAQ_, for example FAQ_THRESHOLD=0.85 or FAQ_LLM_PROVIDER=anthropic.
API keys are NOT stored here: each provider SDK reads its own variable
(ANTHROPIC_API_KEY, OPENAI_API_KEY, GEMINI_API_KEY).
"""

from __future__ import annotations

from functools import lru_cache
from pathlib import Path
from typing import Literal

from pydantic import Field, field_validator
from pydantic_settings import BaseSettings, SettingsConfigDict

DAY_SECONDS = 86_400


class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_prefix="FAQ_", env_file=".env", extra="ignore")

    # --- embeddings -------------------------------------------------------------------------
    embedder: Literal["sentence-transformers", "hash"] = "sentence-transformers"
    # Best safe result in reports/MODEL_COMPARISON.md. Lighter option (470 MB vs 1.1 GB):
    # sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2 - re-run eval, its best T differs.
    embedding_model: str = "sentence-transformers/paraphrase-multilingual-mpnet-base-v2"

    # --- cache ------------------------------------------------------------------------------
    store: Literal["memory", "faiss"] = "memory"
    seed_variants: bool = True  # also cache each FAQ's extra phrasings (data/faqs.json)
    threshold: float = Field(0.83, ge=0.0, le=1.0)  # chosen by `faqcache eval` on the dev half
    top_k: int = Field(3, ge=1, le=20)
    negation_guard: bool = True
    fallthrough: bool = True  # if the best match is blocked by a guard, try the next one
    volatile_ttl_days: float | None = 7.0  # prices / fees / policies expire after N days
    default_ttl_days: float | None = None  # None = never expires
    default_tenant: str = "demomart"

    # --- LLM --------------------------------------------------------------------------------
    llm_provider: Literal["fake", "anthropic", "openai", "gemini", "ollama"] = "fake"
    llm_model: str | None = None  # provider default if empty (Anthropic: claude-opus-5-5)
    llm_effort: Literal["low", "medium", "high"] = "low"  # Anthropic only
    ollama_host: str = "http://localhost:11434"
    fake_llm_latency_ms: float = Field(800.0, ge=0.0)

    # --- files ------------------------------------------------------------------------------
    faqs_path: Path = Path("data/faqs.json")
    test_set_path: Path = Path("data/test_questions.jsonl")
    log_path: Path | None = Path("logs/requests.jsonl")
    reports_dir: Path = Path("reports")

    @field_validator(
        "log_path", "volatile_ttl_days", "default_ttl_days", "llm_model", mode="before"
    )
    @classmethod
    def _empty_means_none(cls, v):
        """FAQ_LOG_PATH= (empty) turns logging off instead of meaning the folder '.'."""
        return None if isinstance(v, str) and v.strip().lower() in ("", "none") else v

    @property
    def volatile_ttl_s(self) -> float | None:
        return None if self.volatile_ttl_days is None else self.volatile_ttl_days * DAY_SECONDS

    @property
    def default_ttl_s(self) -> float | None:
        return None if self.default_ttl_days is None else self.default_ttl_days * DAY_SECONDS


@lru_cache(maxsize=1)
def get_settings() -> Settings:
    return Settings()

7 Step 3: Write the Data (30 FAQs + 100 Labelled Questions)

An exam paper and its answer key. Write the questions before you see how the student (your cache) does, or you will quietly make the exam easier.

This is the most important hour of the project: the numbers in your README are only as honest as this data.

  • data/faqs.json: 30 FAQs of a made-up shop DemoMart. Each has an id (F01…F30), a category, the question, a short generic answer (no names, no order numbers) and 2 variants (other ways to ask, one in Hinglish). Every variant is cached too.
  • data/test_questions.jsonl: one JSON object per line (that is what .jsonl means), 100 lines: 60 paraphrases (2 per FAQ, English + Hinglish, labelled with their FAQ id) and 40 questions that must not hit (label "none"): 16 out of scope, 8 off topic, 8 hard negatives (same words, different question) and 8 negation flips ("Why can't I cancel?").
Never copy a test question into the variants. That is called leakage: the test would then measure memory, not understanding. Our build script checked that no variant equals a test question.

A ticket checker at a cinema: every ticket (data row) is checked for the right shape before anyone enters.

Pydantic models describe the shape of a FAQ and of a test question. Loading fails loudly on a typo (wrong id, unknown label, duplicate) instead of silently producing wrong numbers later.

📄 src/faqcache/data.py 78 lines

  • FAQ and TestItem are Pydantic models: pattern=r"^F\d{2}$" forces ids like F07; Literal[…] limits lang, kind and split to known words.
  • phrasings() returns the main question plus its variants (or only the main one).
  • __test__ = False: the class name starts with "Test", so this line tells pytest "this is not a test class".
  • load_faqs refuses duplicate ids; load_test_set refuses labels that point to a missing FAQ.
  • assign_splits: shuffles the should-hit group and the should-miss group separately with a fixed seed (42), and gives half of each to dev and half to test (a stratified split). The original order is kept.

"""Load and validate the FAQ file and the labelled test set."""

from __future__ import annotations

import json
import random
from pathlib import Path
from typing import Literal

from pydantic import BaseModel, Field

NONE_LABEL = "none"


class FAQ(BaseModel):
    id: str = Field(pattern=r"^F\d{2}$")
    question: str
    answer: str
    category: str
    # Extra ways to ask the same thing. Each one is cached as its own entry (same answer),
    # which lifts the hit rate for phrasings - e.g. Hinglish - that the model scores low.
    variants: list[str] = Field(default_factory=list)

    def phrasings(self, include_variants: bool = True) -> list[str]:
        return [self.question, *self.variants] if include_variants else [self.question]


class TestItem(BaseModel):
    __test__ = False  # tell pytest this is not a test class

    id: str
    question: str
    label: str  # an FAQ id such as "F02", or "none" when the cache must NOT answer
    lang: Literal["en", "hinglish"]
    kind: Literal["paraphrase", "out_of_scope", "off_topic", "hard_negative", "negation_flip"]
    split: Literal["dev", "test"] = "dev"


def load_faqs(path: Path) -> list[FAQ]:
    raw = json.loads(Path(path).read_text(encoding="utf-8"))
    faqs = [FAQ.model_validate(r) for r in raw]
    ids = [f.id for f in faqs]
    if len(ids) != len(set(ids)):
        raise ValueError("duplicate FAQ ids")
    return faqs


def load_test_set(path: Path, faq_ids: set[str] | None = None, seed: int = 42) -> list[TestItem]:
    items = [
        TestItem.model_validate_json(line)
        for line in Path(path).read_text(encoding="utf-8").splitlines()
        if line.strip()
    ]
    if faq_ids is not None:
        bad = [i.id for i in items if i.label != NONE_LABEL and i.label not in faq_ids]
        if bad:
            raise ValueError(f"test items point to unknown FAQ ids: {bad}")
    return assign_splits(items, seed)


def assign_splits(items: list[TestItem], seed: int = 42) -> list[TestItem]:
    """Stratified 50/50 dev/test split (same share of 'should hit' and 'should miss' in each).

    We tune the threshold on *dev* and report it on *test*, so the headline number is not
    measured on the same questions it was tuned on.
    """
    rng = random.Random(seed)
    out: list[TestItem] = []
    for positive in (True, False):

9 Step 5: Safety Rules (guards.py)

A careful shop assistant: before handing over a saved answer she checks that the customer did not say "NOT" ("I did not get my refund"), and she never writes a customer's phone number on the notice board.

Three small rule sets that keep the cache safe. They are plain Python (regular expressions and word lists), so they are fast, testable and easy to explain in an interview.

"""Safety rules: when must the cache NOT be used?

1. Negation guard  - "refund milega" vs "refund nahi milega" look alike to an embedding model
                     but mean opposite things. If exactly one side has a negation word, skip.
2. User-data guard - never cache (or serve from cache) text that holds one person's data:
                     order ids, phone numbers, e-mails, names.
3. TTL policy      - answers about prices, fees, offers or policies expire after N days.
"""

from __future__ import annotations

import re
from dataclasses import dataclass

# ----------------------------------------------------------------------------- negation
NEGATION_WORDS = frozenset(
    {
        # English
        "not", "no", "never", "none", "nothing", "without", "cannot", "cant", "dont", "doesnt",
        "didnt", "wont", "isnt", "arent", "wasnt", "werent", "havent", "hasnt", "hadnt",
        "shouldnt", "wouldnt", "couldnt",
        # Hinglish / Hindi in Latin script
        "nahi", "nahin", "nhi", "nai", "mat", "bina",
    }
)  # fmt: skip
# Phrases that contain a negation word but are not a negation of the question's meaning.
NEGATION_EXCEPTIONS = ("no-cost", "no cost", "no problem", "no worries")

_WORD = re.compile(r"[a-z0-9']+")


def _clean(text: str) -> str:
    text = text.lower().replace("’", "'")
    for phrase in NEGATION_EXCEPTIONS:
        text = text.replace(phrase, " ")
    return text


def has_negation(text: str) -> bool:
    for tok in _WORD.findall(_clean(text)):
        if tok in NEGATION_WORDS or tok.endswith("n't") or tok.replace("'", "") in NEGATION_WORDS:
            return True
    return False


def negation_mismatch(a: str, b: str) -> bool:
    """True when exactly one of the two questions is negated."""
    return has_negation(a) != has_negation(b)


# ----------------------------------------------------------------------------- user data
_USER_DATA_PATTERNS: tuple[tuple[str, re.Pattern[str]], ...] = (
    ("email", re.compile(r"\b[\w.+-]+@[\w-]+\.[\w.-]+\b")),
    ("order_id", re.compile(r"\b(?:ord|order)[\s#:-]*[a-z]{0,3}\d{5,}\b", re.IGNORECASE)),
    ("ref_number", re.compile(r"#\s?\d{4,}")),
    ("phone", re.compile(r"(?<!\d)(?:\+?91[\s-]?)?[6-9]\d{9}(?!\d)")),
    ("long_number", re.compile(r"(?<!\d)\d{8,}(?!\d)")),
    ("name", re.compile(r"\b(?:my name is|i am called|mera naam)\s+[a-z]+", re.IGNORECASE)),
    ("greeting_name", re.compile(r"\b(?:[Dd]ear|[Hh]i|[Hh]ey)\s+[A-Z][a-z]+,")),
)


def find_user_data(text: str) -> str | None:
    """Return the kind of personal data found (e.g. 'order_id'), or None."""
    for kind, pattern in _USER_DATA_PATTERNS:
        if pattern.search(text):
            return kind
    return None


def redact(text: str) -> str:
    """Mask personal data before it is written to a log file."""
    for kind, pattern in _USER_DATA_PATTERNS:
        text = pattern.sub(f"[{kind}]", text)
    return text


# ----------------------------------------------------------------------------- TTL
_VOLATILE = re.compile(
    r"\b(price|prices|pricing|cost|costs|fee|fees|charge|charges|charged|offer|offers|"
    r"discount|discounts|sale|coupon|coupons|emi|interest|policy|policies|kitna|kitne|kitni)\b",
    re.IGNORECASE,
)


def is_volatile(text: str) -> bool:
    return bool(_VOLATILE.search(text))


@dataclass(frozen=True)
class TTLPolicy:
    """How long a cached answer may live, in seconds (None = forever)."""

    volatile_ttl_s: float | None = 7 * 86_400
    default_ttl_s: float | None = None

    def ttl_for(self, question: str, answer: str) -> float | None:
        if is_volatile(question) or is_volatile(answer):
            return self.volatile_ttl_s
        return self.default_ttl_s

10 Step 6: Turn Text into Vectors (embeddings.py)

Giving every sentence a home address on a map of meanings. "Refund kab milega?" lives near "How long does a refund take?" and far from "capital of Australia".

An embedding is a list of numbers (here 768) that captures the meaning of a sentence. We make every vector length 1 (normalise), so the dot product of two vectors is their cosine similarity: 1 = same meaning, near 0 = unrelated.

First run downloads the model (paraphrase-multilingual-mpnet-base-v2, about 1.1 GB) into your Hugging Face cache. On Windows you may see a warning about symlinks: it is harmless (files are copied instead of linked).

"""Turn text into unit-length vectors, so a dot product equals the cosine similarity."""

from __future__ import annotations

import re
import zlib
from collections.abc import Sequence
from typing import Protocol

import numpy as np


class Embedder(Protocol):
    name: str
    dim: int

    def embed(self, texts: Sequence[str]) -> np.ndarray:
        """Return a float32 array of shape (len(texts), dim); every row has length 1."""
        ...


def l2_normalize(x: np.ndarray) -> np.ndarray:
    norms = np.linalg.norm(x, axis=1, keepdims=True)
    norms[norms == 0] = 1.0
    return (x / norms).astype(np.float32)


class SentenceTransformerEmbedder:
    """Real embedding model (downloads once from Hugging Face, then runs locally on CPU).

    `paraphrase-multilingual-MiniLM-L12-v2` (384 dims) handles English and Hinglish;
    `all-MiniLM-L6-v2` is smaller and English-only.
    """

    def __init__(self, model_name: str) -> None:
        from sentence_transformers import SentenceTransformer  # heavy import: keep it lazy

        self.name = model_name
        # E5 models are trained with a "query: " prefix; for question-vs-question similarity
        # the model card says to put "query: " on both sides.
        self.prefix = "query: " if "e5" in model_name.lower() else ""
        self._model = SentenceTransformer(model_name, device="cpu")
        self.dim = int(self.embed(["dimension probe"]).shape[1])

    def embed(self, texts: Sequence[str]) -> np.ndarray:
        vectors = self._model.encode(
            [self.prefix + t for t in texts],
            normalize_embeddings=True,
            convert_to_numpy=True,
            show_progress_bar=False,
        )
        return np.asarray(vectors, dtype=np.float32)


class HashEmbedder:
    """Tiny offline embedder (character 3-grams hashed into buckets).

    It needs no download, so unit tests and CI run in seconds. It only knows spelling,
    not meaning: never use it for the real evaluation.
    """

    def __init__(self, dim: int = 512) -> None:
        self.name = f"hash-3gram-{dim}"
        self.dim = dim

    def embed(self, texts: Sequence[str]) -> np.ndarray:
        out = np.zeros((len(texts), self.dim), dtype=np.float32)
        for row, text in enumerate(texts):
            padded = f"  {re.sub(r'[^a-z0-9 ]', ' ', text.lower())}  "
            for i in range(len(padded) - 2):
                out[row, zlib.crc32(padded[i : i + 3].encode()) % self.dim] += 1.0
        return l2_normalize(out)


def build_embedder(kind: str, model_name: str) -> Embedder:
    if kind == "hash":
        return HashEmbedder()
    return SentenceTransformerEmbedder(model_name)

"""Exact (brute-force) search with NumPy. Fast enough for tens of thousands of entries."""

from __future__ import annotations

import numpy as np

from faqcache.stores.base import CacheEntry, Candidate


class InMemoryVectorStore:
    def __init__(self, dim: int) -> None:
        self.dim = dim
        self._entries: dict[str, CacheEntry] = {}
        self._vectors: dict[str, np.ndarray] = {}
        self._matrix: np.ndarray | None = None  # rebuilt lazily after a change
        self._ids: list[str] = []

    def add(self, entry: CacheEntry, vector: np.ndarray) -> None:
        if vector.shape != (self.dim,):
            raise ValueError(f"expected vector of shape ({self.dim},), got {vector.shape}")
        self._entries[entry.id] = entry
        self._vectors[entry.id] = vector.astype(np.float32)
        self._matrix = None

    def remove(self, entry_id: str) -> None:
        self._entries.pop(entry_id, None)
        if self._vectors.pop(entry_id, None) is not None:
            self._matrix = None

    def search(self, vector: np.ndarray, k: int) -> list[Candidate]:
        if not self._entries:
            return []
        if self._matrix is None:
            self._ids = list(self._vectors)
            self._matrix = np.stack([self._vectors[i] for i in self._ids])
        scores = self._matrix @ vector.astype(np.float32)
        k = min(k, len(self._ids))
        top = np.argpartition(-scores, k - 1)[:k]
        top = top[np.argsort(-scores[top])]
        return [Candidate(self._entries[self._ids[i]], float(scores[i])) for i in top]

    def get(self, entry_id: str) -> CacheEntry | None:
        return self._entries.get(entry_id)

    def entries(self) -> list[CacheEntry]:
        return list(self._entries.values())

    def __len__(self) -> int:
        return len(self._entries)

"""FAISS inner-product index. With unit vectors, inner product == cosine similarity.

IndexFlatIP is exact search. For millions of entries switch to an approximate index
(IndexHNSWFlat or IndexIVFFlat) and re-measure the hit rate: approximate search can miss
the true nearest neighbour.
"""

from __future__ import annotations

import numpy as np

from faqcache.stores.base import CacheEntry, Candidate


class FaissVectorStore:
    def __init__(self, dim: int) -> None:
        import faiss  # optional dependency: pip install "semantic-faq-cache[faiss]"

        self.dim = dim
        self._index = faiss.IndexIDMap2(faiss.IndexFlatIP(dim))
        self._entries: dict[str, CacheEntry] = {}
        self._to_int: dict[str, int] = {}
        self._to_str: dict[int, str] = {}
        self._next = 0

    def add(self, entry: CacheEntry, vector: np.ndarray) -> None:
        if entry.id in self._to_int:
            self.remove(entry.id)
        num = self._next
        self._next += 1
        self._index.add_with_ids(
            vector.reshape(1, -1).astype(np.float32), np.array([num], dtype=np.int64)
        )
        self._entries[entry.id] = entry
        self._to_int[entry.id] = num
        self._to_str[num] = entry.id

    def remove(self, entry_id: str) -> None:
        num = self._to_int.pop(entry_id, None)
        if num is None:
            return
        self._index.remove_ids(np.array([num], dtype=np.int64))
        self._to_str.pop(num, None)
        self._entries.pop(entry_id, None)

    def search(self, vector: np.ndarray, k: int) -> list[Candidate]:
        total = self._index.ntotal
        if total == 0:
            return []
        scores, ids = self._index.search(vector.reshape(1, -1).astype(np.float32), min(k, total))
        out = []
        for score, num in zip(scores[0], ids[0], strict=True):
            if num == -1:
                continue
            out.append(Candidate(self._entries[self._to_str[int(num)]], float(score)))
        return out

    def get(self, entry_id: str) -> CacheEntry | None:
        return self._entries.get(entry_id)

    def entries(self) -> list[CacheEntry]:
        return list(self._entries.values())

    def __len__(self) -> int:
        return len(self._entries)

"""PRODUCTION-STYLE OPTION: Redis + RedisVL SemanticCache.

TEMPLATE - NOT RUN in this repo (no Redis server was available when it was built).
Use it as a starting point; check the RedisVL docs for your installed version, because the
import path moved between releases (older: redisvl.extensions.llmcache).

Start Redis:  docker compose up -d redis      (see docker-compose.yml)
Install:      pip install -e ".[redis]"

Key differences from the in-memory cache:
* RedisVL uses a cosine DISTANCE threshold: distance = 1 - similarity.
  A similarity threshold of 0.80 becomes distance_threshold = 0.20.
* TTL is native (`ttl=` seconds); Redis deletes expired keys for you.
* One index name per tenant keeps customers' caches apart.
"""

from __future__ import annotations

from faqcache.guards import find_user_data, negation_mismatch


def make_redis_cache(tenant: str, similarity_threshold: float, redis_url: str, model: str):
    try:
        from redisvl.extensions.cache.llm import SemanticCache  # newer RedisVL
    except ImportError:  # pragma: no cover
        from redisvl.extensions.llmcache import SemanticCache  # older RedisVL
    from redisvl.utils.vectorize import HFTextVectorizer

    return SemanticCache(
        name=f"faqcache:{tenant}",
        redis_url=redis_url,
        distance_threshold=1.0 - similarity_threshold,
        vectorizer=HFTextVectorizer(model=model),
    )


def redis_lookup(cache, question: str) -> str | None:
    """Return a cached answer or None, applying the same guards as the in-memory cache."""
    if find_user_data(question):
        return None
    for hit in cache.check(prompt=question, num_results=3):
        if not negation_mismatch(question, hit["prompt"]):
            return hit["response"]
    return None


def redis_store(cache, question: str, answer: str, ttl_s: int | None) -> bool:
    if find_user_data(question) or find_user_data(answer):
        return False
    cache.store(prompt=question, response=answer, ttl=ttl_s)
    return True

  • normalize(): lower-case, punctuation to spaces, single spaces. Used for the exact-match drawer (L1).
  • Decision + decide(): walk the candidates from best to worst. Below the threshold: stop (miss). Blocked by the negation guard: remember it and, with fallthrough, try the next candidate; without it, stop. Otherwise: hit. The miss reason is negation_guard if something was blocked, else below_threshold.
  • LookupResult carries everything a caller (or the evaluation) needs, including the query vector, so a miss does not have to embed the question a second time when it is stored (a real speed bug we fixed).
  • SemanticCache.lookup(): (1) exact drawer, (2) embed, (3) store.search(top_k), (4) drop expired entries (lazy eviction), (5) decide(). Wrapped in a lock so the web server's threads do not collide.
  • put(): refuses personal data, reuses the vector if given, then _put_vector() skips duplicates, computes the TTL and stores the entry under a random 12-character id.
  • seed(): embeds all FAQ phrasings in one batch (much faster than one by one).
  • evict_expired(), clear(), __len__: housekeeping.

"""The semantic cache: two layers in front of the LLM.

    question
       |
       v
  [L1 exact]  same text after normalising?            -> hit (score 1.0)
       |
  [L2 semantic] embed -> top-k nearest -> threshold + guards -> hit
       |
     miss -> caller asks the LLM, then calls put()

`decide()` is a pure function. The evaluation code calls the same function, so the numbers
in the report come from exactly the logic that serves real traffic.
"""

from __future__ import annotations

import re
import threading
import time
import uuid
from collections.abc import Callable, Iterable
from dataclasses import dataclass, field

import numpy as np

from faqcache.data import FAQ
from faqcache.embeddings import Embedder
from faqcache.guards import TTLPolicy, find_user_data, negation_mismatch
from faqcache.stores.base import CacheEntry, Candidate, VectorStore


def normalize(text: str) -> str:
    text = re.sub(r"[^\w\s']", " ", text.lower())
    return " ".join(text.split())


@dataclass(frozen=True)
class Decision:
    hit: bool
    candidate: Candidate | None  # the chosen entry on a hit, the best one on a miss
    reason: str  # exact_hit | semantic_hit | below_threshold | negation_guard | empty_cache
    blocked: tuple[Candidate, ...] = ()


def decide(
    question: str,
    candidates: list[Candidate],
    threshold: float,
    *,
    negation_guard: bool = True,
    fallthrough: bool = True,
) -> Decision:
    """Pick a cached answer for `question`, or say why not. Candidates are best-first."""
    if not candidates:
        return Decision(False, None, "empty_cache")
    blocked: list[Candidate] = []
    for cand in candidates:
        if cand.score < threshold:
            break
        if negation_guard and negation_mismatch(question, cand.entry.question):
            blocked.append(cand)
            if not fallthrough:
                break
            continue
        return Decision(True, cand, "semantic_hit", tuple(blocked))
    reason = "negation_guard" if blocked else "below_threshold"
    return Decision(False, candidates[0], reason, tuple(blocked))


@dataclass
class LookupResult:
    hit: bool
    reason: str
    entry: CacheEntry | None
    score: float | None
    latency_ms: float
    candidates: list[Candidate] = field(default_factory=list)
    blocked: tuple[Candidate, ...] = ()
    vector: np.ndarray | None = None  # reuse it in put() on a miss: saves a 2nd embedding


@dataclass
class PutResult:
    stored: bool
    reason: str  # stored | duplicate | user_data:<kind>
    entry: CacheEntry | None = None


class SemanticCache:
    def __init__(
        self,
        embedder: Embedder,
        store: VectorStore,
        *,
        threshold: float = 0.80,
        top_k: int = 3,
        negation_guard: bool = True,
        fallthrough: bool = True,
        ttl: TTLPolicy | None = None,
        clock: Callable[[], float] = time.time,
        namespace: str = "default",
    ) -> None:
        self.embedder = embedder
        self.store = store
        self.threshold = threshold
        self.top_k = top_k
        self.negation_guard = negation_guard
        self.fallthrough = fallthrough
        self.ttl = ttl or TTLPolicy()
        self.clock = clock
        self.namespace = namespace
        self._exact: dict[str, str] = {}  # normalised question -> entry id
        self._lock = threading.RLock()

    # ------------------------------------------------------------------ read
    def lookup(self, question: str) -> LookupResult:
        start = time.perf_counter()
        with self._lock:
            entry = self._live_exact(question)
            if entry is not None:
                cand = Candidate(entry, 1.0)
                return LookupResult(True, "exact_hit", entry, 1.0, _ms(start), [cand])
            vector = self.embedder.embed([question])[0]
            candidates = self._live(self.store.search(vector, self.top_k))
            d = decide(
                question,
                candidates,
                self.threshold,
                negation_guard=self.negation_guard,
                fallthrough=self.fallthrough,
            )
        best = d.candidate
        return LookupResult(
            hit=d.hit,
            reason=d.reason,
            entry=best.entry if (best and d.hit) else None,
            score=best.score if best else None,
            latency_ms=_ms(start),
            candidates=candidates,
            blocked=d.blocked,
            vector=vector,
        )

    # ------------------------------------------------------------------ write
    def put(
        self,
        question: str,
        answer: str,
        *,
        source: str = "llm",
        faq_id: str | None = None,
        vector: np.ndarray | None = None,
    ) -> PutResult:
        kind = find_user_data(question) or find_user_data(answer)
        if kind:
            return PutResult(False, f"user_data:{kind}")
        if vector is None:
            vector = self.embedder.embed([question])[0]
        return self._put_vector(question, answer, vector, source, faq_id)

    def seed(self, faqs: Iterable[FAQ], *, include_variants: bool = True) -> int:
        """Warm the cache with curated FAQ pairs (one batched embedding call)."""
        pairs = [(q, f) for f in faqs for q in f.phrasings(include_variants)]
        vectors = self.embedder.embed([q for q, _ in pairs])
        stored = 0
        for (question, faq), vec in zip(pairs, vectors, strict=True):
            if self._put_vector(question, faq.answer, vec, "faq", faq.id).stored:
                stored += 1
        return stored

    def evict_expired(self) -> int:
        now = self.clock()
        with self._lock:
            dead = [e.id for e in self.store.entries() if e.expired(now)]
            for entry_id in dead:
                self._remove(entry_id)
        return len(dead)

    def clear(self) -> None:
        with self._lock:
            for e in self.store.entries():
                self._remove(e.id)

    def __len__(self) -> int:
        return len(self.store)

    # ------------------------------------------------------------------ internals
    def _put_vector(self, question, answer, vector, source, faq_id) -> PutResult:
        with self._lock:
            if self._live_exact(question) is not None:
                return PutResult(False, "duplicate")
            now = self.clock()
            ttl_s = self.ttl.ttl_for(question, answer)
            entry = CacheEntry(
                id=uuid.uuid4().hex[:12],
                question=question,
                answer=answer,
                created_at=now,
                expires_at=None if ttl_s is None else now + ttl_s,
                source=source,  # type: ignore[arg-type]
                faq_id=faq_id,
            )
            self.store.add(entry, vector)
            self._exact[normalize(question)] = entry.id
            return PutResult(True, "stored", entry)

    def _live_exact(self, question: str) -> CacheEntry | None:
        entry_id = self._exact.get(normalize(question))
        if entry_id is None:
            return None
        entry = self.store.get(entry_id)
        if entry is None:
            self._exact.pop(normalize(question), None)
            return None
        if entry.expired(self.clock()):
            self._remove(entry_id)
            return None
        return entry

    def _live(self, candidates: list[Candidate]) -> list[Candidate]:
        now = self.clock()
        alive = []
        for c in candidates:
            if c.entry.expired(now):
                self._remove(c.entry.id)  # lazy eviction
            else:
                alive.append(c)
        return alive

    def _remove(self, entry_id: str) -> None:
        entry = self.store.get(entry_id)
        if entry is not None:
            self._exact.pop(normalize(entry.question), None)
        self.store.remove(entry_id)


def _ms(start: float) -> float:
    return (time.perf_counter() - start) * 1000.0

    name = "anthropic"

    def __init__(self, model: str = "claude-opus-5-5", effort: str = "low") -> None:
        self.model = model
        self.effort = effort
        self._client = anthropic.Anthropic()  # reads ANTHROPIC_API_KEY or an `ant` profile

            max_tokens=1024,  # deliberately short answers
            betas=["server-side-fallback-2026-07-01"],

class RequestLogger:
    """Append one JSON line per request. Personal data is masked before writing."""

    def __init__(self, path: Path | None) -> None:
        self.path = path
        self._lock = threading.Lock()
        self.counts = {"requests": 0, "hits": 0, "misses": 0, "llm_tokens": 0}
        self._latency_sum = {"cache": 0.0, "llm": 0.0}
        if path:
            path.parent.mkdir(parents=True, exist_ok=True)

    def log(self, question: str, ans: Answer, provider: str) -> None:
        record = {
            "ts": round(time.time(), 3),
            "tenant": ans.tenant,
            "question": redact(question),
            "hit": ans.source == "cache",
            "reason": ans.reason,
            "similarity": None if ans.similarity is None else round(ans.similarity, 4),
            "matched_question": ans.matched_question,
            "latency_ms": round(ans.latency_ms, 2),
            "input_tokens": ans.input_tokens,
            "output_tokens": ans.output_tokens,
            "provider": provider,
        }
        with self._lock:
            self.counts["requests"] += 1
            self.counts["hits" if record["hit"] else "misses"] += 1
            self.counts["llm_tokens"] += ans.input_tokens + ans.output_tokens
            self._latency_sum[ans.source] += ans.latency_ms
            if self.path:
                with self.path.open("a", encoding="utf-8") as fh:
                    fh.write(json.dumps(record, ensure_ascii=False) + "\n")

    def stats(self) -> dict:
        with self._lock:
            c = dict(self.counts)
            n = c["requests"]
            c["hit_rate"] = round(c["hits"] / n, 4) if n else 0.0
            c["avg_cache_latency_ms"] = (
                round(self._latency_sum["cache"] / c["hits"], 2) if c["hits"] else None
            )
            c["avg_llm_latency_ms"] = (
                round(self._latency_sum["llm"] / c["misses"], 2) if c["misses"] else None
            )
            return c


class FAQBot:
    """One cache per tenant (customer), so company A never gets company B's answers."""

    def __init__(
        self,
        cache_factory: Callable[[str], SemanticCache],
        llm: LLMClient,
        *,
        system_prompt: str,
        logger: RequestLogger | None = None,
        default_tenant: str = "demomart",
    ) -> None:
        self._cache_factory = cache_factory
        self._caches: dict[str, SemanticCache] = {}
        self._lock = threading.Lock()
        self.llm = llm
        self.system_prompt = system_prompt
        self.logger = logger or RequestLogger(None)
        self.default_tenant = default_tenant

    def cache_for(self, tenant: str | None = None) -> SemanticCache:
        tenant = tenant or self.default_tenant
        with self._lock:
            if tenant not in self._caches:
                self._caches[tenant] = self._cache_factory(tenant)
            return self._caches[tenant]

    def ask(self, question: str, tenant: str | None = None, *, use_cache: bool = True) -> Answer:
        tenant = tenant or self.default_tenant
        start = time.perf_counter()
        cache = self.cache_for(tenant)
        personal = find_user_data(question)
        similarity = matched = vector = None
        lookup_ms = 0.0
        reason = "cache_disabled" if not use_cache else "user_data" if personal else ""

        if use_cache and not personal:
            res = cache.lookup(question)
            lookup_ms = res.latency_ms
            similarity = res.score
            if res.hit and res.entry is not None:
                ans = Answer(
                    answer=res.entry.answer,
                    source="cache",
                    reason=res.reason,
                    similarity=res.score,
                    matched_question=res.entry.question,
                    latency_ms=_ms(start),
                    input_tokens=0,
                    output_tokens=0,
                    stored=False,
                    tenant=tenant,
                    lookup_ms=lookup_ms,
                )
                self.logger.log(question, ans, "cache")
                return ans
            reason = res.reason
            vector = res.vector
            if res.candidates:
                matched = res.candidates[0].entry.question

        llm_start = time.perf_counter()
        resp = self.llm.generate(question, self.system_prompt)
        llm_ms = _ms(llm_start)
        stored = False
        if use_cache and not personal and resp.cacheable:
            stored = cache.put(question, resp.text, source="llm", vector=vector).stored
        ans = Answer(
            answer=resp.text,
            source="llm",
            reason=reason,
            similarity=similarity,
            matched_question=matched,
            latency_ms=_ms(start),
            input_tokens=resp.input_tokens,
            output_tokens=resp.output_tokens,
            stored=stored,
            tenant=tenant,
            lookup_ms=lookup_ms,
            llm_ms=llm_ms,
        )
        self.logger.log(question, ans, self.llm.name)
        return ans


def answer_dict(ans: Answer) -> dict:
    d = asdict(ans)
    for k in ("latency_ms", "lookup_ms", "llm_ms"):
        d[k] = round(d[k], 2)
    if d["similarity"] is not None:
        d["similarity"] = round(d["similarity"], 4)
    return d


def _ms(start: float) -> float:
    return (time.perf_counter() - start) * 1000.0

def build_bot(
    settings: Settings,
    *,

    seed: bool = True,
) -> FAQBot:
    faqs = faqs if faqs is not None else load_faqs(settings.faqs_path)
    embedder = embedder or build_embedder(settings.embedder, settings.embedding_model)
    for text in ("warm-up", "warm up the model", "a slightly longer warm-up sentence here"):
        embedder.embed([text])  # first calls are slow (lazy init); pay that at start-up

    def cache_factory(tenant: str) -> SemanticCache:

"""Measure the cache: threshold sweep, dev/test hold-out, guard ablation, end-to-end replay.

Definitions (used everywhere in the reports):
* hit         - the cache returned a saved answer.
* correct hit - a hit whose saved FAQ is the labelled one.
* false hit   - a hit on a question labelled "none", or on the WRONG FAQ.  (the dangerous one)
* hit rate    - hits / all questions. With 60 paraphrases and 40 "none" questions the best
                possible hit rate is 60%.
* recall      - correct hits / paraphrase questions (out of 60).
"""

from __future__ import annotations

import statistics
import time
from dataclasses import asdict, dataclass

import numpy as np

from faqcache.cache import SemanticCache, decide
from faqcache.data import NONE_LABEL, TestItem
from faqcache.stores.base import Candidate


@dataclass
class Probe:
    """One test question looked up once against the warm cache (top-k kept)."""

    item: TestItem
    candidates: list[Candidate]
    lookup_ms: float  # real measured time: normalise + embed + vector search + guards


@dataclass
class SweepRow:
    threshold: float
    n: int
    hits: int
    hit_rate: float
    correct_hits: int
    false_hits: int
    recall: float
    precision: float
    llm_calls: int
    llm_calls_saved_pct: float
    est_avg_latency_ms: float


def probe_all(cache: SemanticCache, items: list[TestItem], warmup: int = 3) -> list[Probe]:
    for item in items[:warmup]:  # first calls are slower (lazy init); don't time them
        cache.lookup(item.question)
    probes = []
    for item in items:
        res = cache.lookup(item.question)
        probes.append(Probe(item, res.candidates, res.latency_ms))
    return probes


def evaluate(
    probes: list[Probe],
    threshold: float,
    *,
    negation_guard: bool = True,
    fallthrough: bool = True,
    llm_latency_ms: float = 800.0,
) -> tuple[SweepRow, list[dict]]:
    rows, hits, correct, false = [], 0, 0, 0
    positives = sum(p.item.label != NONE_LABEL for p in probes)
    latency = []
    for p in probes:
        d = decide(
            p.item.question,
            p.candidates,
            threshold,
            negation_guard=negation_guard,
            fallthrough=fallthrough,
        )
        matched = d.candidate.entry.faq_id if (d.hit and d.candidate) else None
        is_correct = d.hit and matched == p.item.label
        is_false = d.hit and not is_correct
        hits += d.hit
        correct += is_correct
        false += is_false
        latency.append(p.lookup_ms + (0.0 if d.hit else llm_latency_ms))
        rows.append(
            {
                "id": p.item.id,
                "question": p.item.question,
                "label": p.item.label,
                "kind": p.item.kind,
                "hit": d.hit,
                "reason": d.reason,
                "matched": matched,
                "score": round(d.candidate.score, 4) if d.candidate else None,
                "outcome": "correct_hit"
                if is_correct
                else "FALSE_HIT"
                if is_false
                else "missed"
                if p.item.label != NONE_LABEL
                else "correct_miss",
            }
        )
    n = len(probes)
    row = SweepRow(
        threshold=round(threshold, 4),
        n=n,
        hits=hits,
        hit_rate=round(hits / n, 4) if n else 0.0,
        correct_hits=correct,
        false_hits=false,
        recall=round(correct / positives, 4) if positives else 0.0,
        precision=round(correct / hits, 4) if hits else 1.0,
        llm_calls=n - hits,
        llm_calls_saved_pct=round(100 * hits / n, 2) if n else 0.0,
        est_avg_latency_ms=round(statistics.fmean(latency), 2) if latency else 0.0,
    )
    return row, rows


def sweep(probes, thresholds, **kw) -> list[SweepRow]:
    return [evaluate(probes, t, **kw)[0] for t in thresholds]


def grid(start: float, stop: float, step: float) -> list[float]:
    n = int(round((stop - start) / step))
    return [round(start + i * step, 4) for i in range(n + 1)]


def choose_threshold(rows: list[SweepRow], max_false_hits: int = 0) -> SweepRow:
    """Most hits while false hits <= max_false_hits; ties go to the higher (safer) threshold."""
    ok = [r for r in rows if r.false_hits <= max_false_hits]
    if not ok:  # nothing is safe enough: take the fewest false hits
        return min(rows, key=lambda r: (r.false_hits, -r.hits))
    return max(ok, key=lambda r: (r.hits, r.threshold))


def exact_match_baseline(probes: list[Probe], cached_questions: list[str]) -> dict:
    """What a plain key-value cache (same text after normalising) would catch."""
    from faqcache.cache import normalize

    index = {normalize(q) for q in cached_questions}
    hits = [p for p in probes if normalize(p.item.question) in index]
    return {"hits": len(hits), "hit_rate": round(len(hits) / len(probes), 4)}


def score_bands(probes: list[Probe], width: float = 0.05) -> list[dict]:
    """Histogram of the top-1 similarity: 'should hit' vs 'should miss' questions."""
    pos = [p.candidates[0].score for p in probes if p.candidates and p.item.label != NONE_LABEL]
    neg = [p.candidates[0].score for p in probes if p.candidates and p.item.label == NONE_LABEL]
    edges = np.arange(0.0, 1.0001 + width, width)
    out = []
    for lo, hi in zip(edges[:-1], edges[1:], strict=True):
        a = sum(lo <= s < hi for s in pos)
        b = sum(lo <= s < hi for s in neg)
        if a or b:
            out.append({"band": f"{lo:.2f}-{hi:.2f}", "should_hit": a, "should_miss": b})
    return out


def guard_ablation(probes, threshold, llm_latency_ms) -> dict:
    variants = {
        "no_guard": dict(negation_guard=False, fallthrough=False),
        "guard_skip": dict(negation_guard=True, fallthrough=False),
        "guard_fallthrough": dict(negation_guard=True, fallthrough=True),
    }
    results, details = {}, {}
    for name, kw in variants.items():
        row, rows = evaluate(probes, threshold, llm_latency_ms=llm_latency_ms, **kw)
        results[name] = asdict(row)
        details[name] = {r["id"]: r for r in rows}
    caught, cost, rescued = [], [], []
    for item_id, base in details["no_guard"].items():
        with_guard = details["guard_fallthrough"][item_id]
        if base["outcome"] == "FALSE_HIT" and with_guard["outcome"] != "FALSE_HIT":
            caught.append({**with_guard, "would_have_matched": base["matched"]})
        if base["outcome"] == "correct_hit" and with_guard["outcome"] != "correct_hit":
            cost.append(with_guard)
        if base["outcome"] != "correct_hit" and with_guard["outcome"] == "correct_hit":
            rescued.append(with_guard)
    return {"variants": results, "caught": caught, "lost": cost, "rescued": rescued}

def replay(bot_factory, items: list[TestItem]) -> dict:
    """Run every question through the real request path twice: without and with the cache."""

    def run(use_cache: bool) -> dict:
        bot = bot_factory()
        bot.cache_for()  # seed before timing
        lat, hits, tokens = [], 0, 0
        hit_ms, miss_lookup_ms, llm_ms = [], [], []
        start = time.perf_counter()
        for item in items:
            ans = bot.ask(item.question, use_cache=use_cache)
            lat.append(ans.latency_ms)
            hits += ans.source == "cache"
            tokens += ans.input_tokens + ans.output_tokens
            if ans.source == "cache":
                hit_ms.append(ans.latency_ms)
            else:
                llm_ms.append(ans.llm_ms)
                if use_cache:
                    miss_lookup_ms.append(ans.lookup_ms)

        def stats(xs):
            if not xs:
                return None
            return {
                "mean": round(statistics.fmean(xs), 2),
                "p50": round(statistics.median(xs), 2),
                "p95": round(float(np.percentile(xs, 95)), 2),
                "max": round(max(xs), 2),
            }

        return {
            "requests": len(items),
            "llm_calls": len(items) - hits,
            "cache_hits": hits,
            "tokens": tokens,
            "avg_latency_ms": round(statistics.fmean(lat), 2),
            "p50_latency_ms": round(statistics.median(lat), 2),
            "p95_latency_ms": round(float(np.percentile(lat, 95)), 2),
            "wall_s": round(time.perf_counter() - start, 2),
            "breakdown_ms": {
                "cache_hit_total": stats(hit_ms),
                "cache_lookup_on_miss": stats(miss_lookup_ms),
                "llm_call": stats(llm_ms),
            },
            "provider": bot.llm.name,
        }

    before, after = run(False), run(True)
    saved = 100 * (before["llm_calls"] - after["llm_calls"]) / before["llm_calls"]
    speed = 100 * (before["avg_latency_ms"] - after["avg_latency_ms"]) / before["avg_latency_ms"]
    return {
        "without_cache": before,
        "with_cache": after,
        "llm_calls_saved_pct": round(saved, 2),
        "avg_latency_reduction_pct": round(speed, 2),
    }

from __future__ import annotations

import csv
import json
from dataclasses import asdict
from pathlib import Path

from faqcache.evaluation import SweepRow


def md_table(rows: list[dict], cols: list[str] | None = None) -> str:
    if not rows:
        return "_(none)_\n"
    cols = cols or list(rows[0])
    out = ["| " + " | ".join(cols) + " |", "|" + "---|" * len(cols)]
    for r in rows:
        out.append("| " + " | ".join(_fmt(r.get(c)) for c in cols) + " |")
    return "\n".join(out) + "\n"


def sweep_table(rows: list[SweepRow], chosen: float | None = None) -> str:
    cols = ["threshold", "hits", "hit_rate", "correct_hits", "false_hits", "recall",
            "precision", "llm_calls", "est_avg_latency_ms"]  # fmt: skip
    dicts = []
    for r in rows:
        d = asdict(r)
        if chosen is not None and abs(r.threshold - chosen) < 1e-9:
            d["threshold"] = f"**{r.threshold:.2f}** <- chosen"
        dicts.append(d)
    return md_table(dicts, cols)


def write_csv(path: Path, rows: list[SweepRow]) -> None:
    with path.open("w", newline="", encoding="utf-8") as fh:
        w = csv.DictWriter(fh, fieldnames=list(asdict(rows[0])))
        w.writeheader()
        for r in rows:
            w.writerow(asdict(r))


def write_json(path: Path, data) -> None:
    path.write_text(json.dumps(data, indent=2, ensure_ascii=False, default=str), encoding="utf-8")


def _fmt(v) -> str:
    if isinstance(v, float):
        return f"{v:.4f}".rstrip("0").rstrip(".") if v < 10 else f"{v:.1f}"
    return "" if v is None else str(v).replace("|", "/")

"""HTTP API.   Run:  uvicorn faqcache.api:app --port 8000   then open http://localhost:8000/docs"""

from __future__ import annotations

from contextlib import asynccontextmanager

from fastapi import FastAPI, Request
from pydantic import BaseModel, Field

from faqcache import __version__
from faqcache.config import get_settings
from faqcache.factory import build_bot
from faqcache.service import FAQBot, answer_dict


class AskRequest(BaseModel):
    question: str = Field(min_length=1, max_length=1000, examples=["refund kab milega?"])
    tenant: str | None = Field(default=None, pattern=r"^[a-z0-9_-]{1,40}$")


class AskResponse(BaseModel):
    answer: str
    source: str
    reason: str
    similarity: float | None
    matched_question: str | None
    latency_ms: float
    input_tokens: int
    output_tokens: int
    stored: bool
    tenant: str
    lookup_ms: float
    llm_ms: float


def create_app(bot: FAQBot | None = None) -> FastAPI:
    @asynccontextmanager
    async def lifespan(app: FastAPI):
        app.state.bot = bot or build_bot(get_settings())
        app.state.bot.cache_for()  # build + seed the default tenant at start-up, not on 1st call
        yield

    app = FastAPI(title="Semantic FAQ Cache", version=__version__, lifespan=lifespan)

    @app.get("/healthz")
    def healthz() -> dict:
        return {"status": "ok"}

    @app.post("/v1/ask", response_model=AskResponse)
    def ask(body: AskRequest, request: Request) -> dict:
        # plain `def`: FastAPI runs it in a thread pool, so blocking model calls are fine
        return answer_dict(request.app.state.bot.ask(body.question, body.tenant))

    @app.get("/v1/stats")
    def stats(request: Request) -> dict:
        b: FAQBot = request.app.state.bot
        return {**b.logger.stats(), "cache_entries": len(b.cache_for()), "provider": b.llm.name}

    return app


app = create_app()

# Semantic cache for an FAQ bot

Answer repeat customer questions from a cache when the **meaning** matches, call the LLM only on
a miss, and **prove it with numbers**: hit rate, false hits and latency, measured on a labelled
English + Hinglish test set.

> **Result** (100 labelled questions, `paraphrase-multilingual-mpnet-base-v2`, CPU):
> **cache hit rate 20% at threshold 0.83 with 0 false hits** (0 on the held-out half too);
> **LLM calls down 20%** (100 → 80); in the end-to-end replay the **average latency fell from
> 801 ms to 696 ms**, with the LLM simulated at 800 ms per call. A cache hit is served in
> about 50 ms. An exact-text cache hit **0** of the same 100 questions.

All numbers come from `reports/` and were produced by the commands below on 19 Nov 2026
(Windows 11 laptop, Python 3.14, sentence-transformers 6.3, torch 2.15 CPU).

## How it works

```mermaid
flowchart LR
    Q[question] --> P{personal data?<br/>order id, phone, e-mail}
    P -- yes --> L
    P -- no --> X{L1: same text<br/>after normalising?}
    X -- yes --> H[cached answer]
    X -- no --> E[embed<br/>~30 ms CPU] --> S[top-3 nearest<br/>cached questions]
    S --> T{similarity ≥ T<br/>and negation guard OK?}
    T -- yes --> H
    T -- no --> L[LLM call] --> C{cacheable?<br/>no personal data,<br/>not a refusal}
    C -- yes --> W[save Q + A<br/>TTL 7 days for prices/policies]
    C -- no --> A[answer]
    W --> A
    H --> A
```

* **Embeddings:** questions become unit-length vectors, so a dot product is the cosine
  similarity and search is one matrix multiply (NumPy) or `faiss.IndexFlatIP`.
* **Seeding:** the 30 FAQs are cached up front, each with 2 extra phrasings (90 entries).
* **Guards:** a negation guard ("refund milega" ≠ "refund nahi milega"), a personal-data guard
  (never cache or serve one person's data), TTL for volatile answers, and no caching of
  refusals or cut-off answers.
* **Multi-tenant:** one cache per tenant, so customer A never receives customer B's answers.
* **One source of truth:** the pure `decide()` function is used by the live cache *and* by the
  evaluation, so the report measures the exact code that serves traffic.

## Results

### Threshold sweep (all 100 questions: 60 should hit, 40 should not)

| threshold | hits | correct | **false hits** | recall (of 60) | precision | LLM calls |
|---|---|---|---|---|---|---|
| 0.75 | 36 | 31 | **5** | 52% | 86% | 64 |
| 0.80 | 26 | 24 | **2** | 40% | 92% | 74 |
| 0.85 | 16 | 16 | 0 | 27% | 100% | 84 |
| 0.90 | 8 | 8 | 0 | 13% | 100% | 92 |
| 0.95 | 1 | 1 | 0 | 2% | 100% | 99 |

**Why 0.83?** It was picked on a **dev half** (50 questions, 0.01 grid, rule: most hits with zero
false hits) and then checked on the **test half** it never saw: 8/30 correct hits, **0 false
hits**. On all 100 questions it gives 20 hits, all correct. Lower thresholds catch more
paraphrases but start returning wrong answers. In a support bot one confidently wrong answer
costs more than one LLM call, so the rule is "zero false hits first".

### The negation guard (at T = 0.83)

| | hits | correct | false hits |
|---|---|---|---|
| no guard | 24 | 19 | **5** |
| guard (skip if blocked) | 19 | 19 | 0 |
| guard + fall-through to next candidate | **20** | **20** | **0** |

False hits it caught, with no correct hit lost:
* "Why **can't** I cancel my order?" would have received the *how to cancel* answer.
* "Mera password reset **nahi** ho raha" would have received the *how to reset* answer.
* "My discount code **isn't** working, why?" matched *how to apply a coupon* first; the
  fall-through picked the right FAQ, *coupon not working* (0.83).

### Embedding model comparison (`reports/MODEL_COMPARISON.md`)

| model | extra phrasings | best T (dev) | correct / false (all 100) | correct / false at fixed 0.80 | lookup |
|---|---|---|---|---|---|
| all-MiniLM-L6-v2 (English only) | on | 0.80 | 15 / 0 | 15 / 0 | 10 ms |
| paraphrase-multilingual-MiniLM-L12-v2 | off | 0.68 | 20 / 2 | 8 / 1 | 18 ms |
| paraphrase-multilingual-MiniLM-L12-v2 | on | 0.89 | 6 / 0 | 13 / 2 | 20 ms |
| paraphrase-multilingual-mpnet-base-v2 | off | 0.69 | 29 / 3 | 15 / 1 | 26 ms |
| **paraphrase-multilingual-mpnet-base-v2** | **on** | **0.83** | **20 / 0** | 24 / 2 | 27 ms |
| multilingual-e5-small | on | 0.95 | 4 / 0 | 41 / **57** | 15 ms |

What this table teaches:
1. **A threshold is not portable.** At 0.80, e5-small returns 57 false hits, because its
   scores all sit high. Re-run the sweep whenever you change the model.
2. **Extra phrasings help recall at a fixed threshold** (mpnet: 15 → 24 correct at 0.80), but
   more entries also give "none" questions more near neighbours. Under a zero-false-hit rule the
   chosen threshold goes up, so the net gain is smaller than it looks.
3. **Romanised Hinglish is the weak spot.** For "Refund kab tak milega?" even the best
   cached match scores only 0.69. These models learned Hindi mostly in Devanagari script.

### End-to-end replay (`reports/replay.json`)

Every test question goes through the real request path twice, first with the cache off and then
on. **The LLM here is the offline stand-in, which sleeps 800 ms per call (simulated)**; all
cache-side times are measured.

| | LLM calls | tokens | avg latency | p50 | p95 |
|---|---|---|---|---|---|
| without cache | 100 | 147,678 | 801 ms | 801 ms | 801 ms |
| with cache | **80** | 118,038 | **696 ms** | 848 ms | 890 ms |

## Interview talking points

* **Why semantic, not exact?** An exact cache hit 0 of the 100 questions: people never type the
  same sentence twice. A semantic cache hit 20 with zero wrong answers.
* **The false-hit risk.** A wrong cached answer is served fast *and* confidently to every
  later asker. That's why the threshold rule puts false hits first, why the negation guard
  exists (5 → 0 false hits), and why personal answers are never cached.
* **How I picked the number.** Swept 0.50-0.99, picked on a dev half and reported on a held-out
  half, so I'm not grading my own exam. The threshold must be re-tuned for each model.
* **Honest limits.** The test set is small (100) and written by one person, and the extra
  phrasings were written by the same person (risk of optimism). Hinglish recall is weak. LLM
  latency in the replay is simulated. Lookup latency is one laptop's CPU and it jitters: an
  embedding run right after the CPU sat idle was measured at 61 ms on average, with spikes up
  to 430 ms.
* **What changes at scale.** Redis/RedisVL as a shared cache for many API workers (template in
  `stores/redis_template.py`); an approximate index (HNSW) and a recall re-check; TTL and
  invalidation when a policy changes; one namespace per tenant; GPU or batched embeddings;
  metrics (hit rate, false-hit reports from 👎 feedback, p95 latency); a cross-encoder
  re-ranker on the top 3 to raise recall without raising false hits.

## Day 0 (30 minutes): the idea in plain words

**Life example.** A shop helper gets asked "where is my order?" 200 times a day. After the
first time, she writes the answer on a sticky note. When someone asks "mera order kahan hai?"
she sees it *means the same thing* and reads the note. That's much faster than phoning the
head office (the LLM) every time.

* **Exact cache** = the note only works when the words match exactly. "Where is my order?"
  and "where's my order" count as different questions. Almost useless for real chat.
* **Semantic cache** = turn every question into a list of numbers (an *embedding*) that
  captures its meaning. Questions with similar meanings get similar numbers. If the new
  question is close enough to a saved one, reuse that saved answer.
* **Threshold** = how close counts as "the same question". Too low gives wrong answers
  (*false hits*); too high means the cache almost never answers.
* **The proof** = a labelled test set, so you can *measure* the hit rate and false hits
  instead of guessing.

```
question --> [L1 exact match?] --yes--> saved answer (about 0 ms)
                 | no
                 v
            embed question (about 10-15 ms on a CPU)
                 |
            nearest saved questions (top-k) --> similarity >= T ?  --> guards OK? --> HIT
                 |                                                        |
                 +------------------------- MISS <------------------------+
                                             |
                                 ask the LLM (hundreds of ms) --> save Q+A (if safe) --> answer
```

```
├── reports/                  # generated numbers (committed, so the README can cite them)

```

**Why this shape?** Each file has one job, and the parts talk through small interfaces
(`Embedder`, `VectorStore`, `LLMClient`). You can swap NumPy for FAISS, or Claude for Ollama,
without touching the cache logic. Interviewers call this *separation of concerns* and
*dependency injection*. `src/` layout stops tests from accidentally importing local files
instead of the installed package.

## Day 1: build it (about 6-7 hours)

### Step 1.1: set up the project (30 min)
* Create the folders above and `pyproject.toml` (copy ours and read every line).
* Create a virtual environment and install in *editable* mode:
  ```bash
  python -m venv .venv
  # Windows: .venv\Scripts\activate      macOS/Linux: source .venv/bin/activate
  pip install -e ".[dev,faiss]"
  ```
* `git init`, add `.gitignore`, commit "skeleton".
* **Done when:** `python -c "import faqcache; print(faqcache.__version__)"` prints `1.0.0`.

### Step 1.2: write the data (60-90 min). This is the most important hour.
* `data/faqs.json`: pick one domain (we use a made-up shop, *DemoMart*). Write 30 FAQs with
  `id`, `question`, `answer`, `category`. Keep answers short and **generic**: no names and no
  order numbers.
* `data/test_questions.jsonl`: 100 lines. 60 **paraphrases** (2 per FAQ: one English, one
  Hinglish) labelled with the FAQ id. 40 that must **not** hit, labelled `"none"`:
  * 16 *out of scope* but shop-like ("Do you sell medicines?")
  * 8 *off topic* ("Who won the cricket match?")
  * 8 **hard negatives**: same words, different question ("How do I reset my **UPI PIN**?"
    vs the FAQ "How do I reset my **password**?")
  * 8 **negation flips** ("Why **can't** I cancel my order?" vs "How do I cancel my order?")
* **Rule:** write the test questions *before* you look at any similarity scores, or you will
  bend the test toward your system without noticing.
* **Done when:** `pytest tests/test_evaluation_and_data.py` passes (it checks 30/100/60/40).

### Step 1.3: settings (20 min). File `config.py`
* One `Settings` class (pydantic-settings) reads `FAQ_THRESHOLD`, `FAQ_LLM_PROVIDER`, …
  from the environment or `.env`. No magic numbers scattered through the code.
* API keys are *not* settings: each SDK reads its own variable (`ANTHROPIC_API_KEY`…).

### Step 1.4: embeddings (40 min). File `embeddings.py`
* An `Embedder` *Protocol* with `embed(texts) -> (n, dim) float32` array.
* `SentenceTransformerEmbedder` uses `normalize_embeddings=True`. Every vector then has
  length 1, so **dot product = cosine similarity**. Search becomes one matrix multiply.
* Model: start with `paraphrase-multilingual-MiniLM-L12-v2` (English + Hindi, small), or
  `all-MiniLM-L6-v2` if you only have English. On Day 2, `faqcache compare` showed that
  `paraphrase-multilingual-mpnet-base-v2` gave the best *safe* result on this data, so it is
  the repo's default now. Let measurements choose the model, not habit.
* `HashEmbedder`: a tiny offline fake for unit tests (spelling only, no meaning).
* **Check:**
  ```python
  from faqcache.embeddings import SentenceTransformerEmbedder
  e = SentenceTransformerEmbedder("sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2")
  v = e.embed(["How long does a refund take?", "Refund kab milega?", "Capital of Australia?"])
  print(v @ v.T)   # row 0 vs 1 should be higher than row 0 vs 2
  ```

### Step 1.5: vector store (40 min). Folder `stores/`
* `CacheEntry` (id, question, answer, created_at, expires_at, source, faq_id) and
  `Candidate` (entry + score).
* `InMemoryVectorStore`: keep vectors in a NumPy matrix; `scores = M @ q`; take the top-k.
  Exact search, fine up to tens of thousands of entries.
* `FaissVectorStore`: the same thing with `faiss.IndexFlatIP` (inner product).
  `test_faiss_store_matches_memory_store` proves both return the same answers.

### Step 1.6: the cache (90 min). File `cache.py`
* `decide(question, candidates, threshold)` is a **pure function** (no I/O). It walks the
  candidates best-first: below the threshold → miss; blocked by a guard → skip (or try the
  next one); otherwise → hit. Keep it pure so the evaluation reuses *exactly* this logic.
* `SemanticCache.lookup()`: L1 exact dictionary (normalised text) → embed → `store.search`
  → drop expired entries → `decide()`. Returns hit/miss, reason, score and latency.
* `put()`: refuse personal data, compute TTL, store vector + entry.
* `seed(faqs)`: embed all 30 FAQ questions in **one batch** (much faster than one by one).

### Step 1.7: LLM providers (40 min). Folder `llm/`
* Interface `generate(question, system) -> LLMResponse(text, input_tokens, output_tokens,
  model, cacheable)`.
* `FakeLLM` first (no key, sleeps N ms), then real ones: `anthropic_client.py`,
  `openai_client.py`, `gemini_client.py`, `ollama_client.py`.
* `cacheable=False` for refusals or cut-off answers. **Never cache a bad answer**: the cache
  would repeat it for everyone.

### Step 1.8: the bot + logging (40 min). File `service.py`
* `FAQBot.ask()`: personal data? → skip the cache. Otherwise `lookup` → hit: return the saved
  answer. Miss: call the LLM → `put` (if cacheable) → return.
* `RequestLogger` writes one JSON line per request: question (**personal data masked**),
  hit/miss, reason, similarity, latency ms, tokens.
* **Done when:**
  ```bash
  faqcache ask "refund kab milega?"
  faqcache demo
  ```
  Expected: first question → `LLM (miss)`, the repeats → `CACHE HIT` in a few ms.

### Step 1.9: tests for Day 1 (30 min)
* `pytest` should pass offline: exact hit, semantic hit, miss, threshold boundary, user-data
  refusal, duplicate, unit-length vectors, FAISS parity.
* Commit: "day 1: working semantic cache".

## Day 2: tune and measure (about 6-7 hours)

### Step 2.1: probe once, sweep many times (60 min). File `evaluation.py`
* Seed the cache with the FAQs. Look up each of the 100 questions **once** and keep its
  top-k candidates plus the measured lookup time (`probe_all`).
* For each threshold, re-run `decide()` on the stored candidates. No re-embedding needed,
  so a 50-point sweep takes milliseconds.
* Count, per threshold: hits, **correct hits**, **false hits** (a "none" question got an
  answer, *or* the wrong FAQ was returned), recall (correct / 60), LLM calls, estimated
  average latency (lookup + assumed LLM time on a miss).

### Step 2.2: run the sweep (30 min)
```bash
faqcache eval          # writes reports/EVAL_REPORT.md, sweep_*.csv, summary.json
```
* Section 1 of the report is the 0.75-0.95 table from the project brief.
* **Read section 4 (score bands)**. If the "should hit" and "should miss" columns overlap,
  no threshold can be perfect, and you can explain that in an interview.

### Step 2.3: choose the threshold honestly (30 min)
* If you pick T on the same 100 questions you report on, you are grading your own exam.
* `data.assign_splits` makes a stratified 50/50 **dev/test** split. Pick T on dev (rule:
  most hits with zero false hits; ties → the higher, safer T), then report it on test.

### Step 2.4: negation guard (60 min). File `guards.py`
* `has_negation()` looks for not / no / never / n't / nahi / nahin / nhi / mat / without /
  bina, but ignores phrases like "no-cost EMI". `negation_mismatch(a, b)` is true when
  exactly one side is negated.
* In `decide()`: if the best match is blocked, either **skip** (miss) or **fall through**
  to the next candidate above T (top-k).
* The report's section 5 compares no guard / skip / fall-through, and lists which false hits
  the guard **caught** and which correct hits it **cost**. Keep 2-3 caught examples for the
  README.

### Step 2.5: cache hygiene (45 min)
* **TTL:** answers that mention price / fee / charge / offer / policy / EMI expire after
  `FAQ_VOLATILE_TTL_DAYS` (default 7); others never expire. Expired entries are evicted
  lazily on lookup (and by `evict_expired()`). Tested with a fake clock.
* **Personal data:** regexes for order ids, phone numbers, e-mails, "my name is…" and
  greetings like "Hi Rahul,". Such questions skip the cache completely, and such answers are
  never stored. Logs are masked with `redact()`.

### Step 2.6: improve, then re-measure (90 min)
Change **one** thing at a time and re-run `faqcache eval` after each:
1. **Extra phrasings**: each FAQ gets 2 more ways to ask (one Hinglish) in `faqs.json`
   (`variants`). Each one becomes its own cache entry with the same answer. Never copy a
   test question into the variants: that is leakage.
2. **Embedding model**: `faqcache compare` runs the same evaluation for several models,
   with phrasings on and off → `reports/MODEL_COMPARISON.md`. Note that the best threshold
   **differs per model**: a threshold is not portable.
* What we actually found (19 Nov 2026, see the README): the brief's 0.75-0.95 range was too
  high for some models and too low for others (e5-small: 57 false hits at 0.80). Romanised
  Hinglish scored low on every model. The negation guard turned 5 false hits into 0 at
  T = 0.83 without losing a correct hit.
* Commit: "day 2: measured + tuned".

What we did, in the real order

  1. First version used the brief's model paraphrase-multilingual-MiniLM-L12-v2 and cached only the 30 main questions. Result: at the brief's thresholds 0.75–0.95 only 14 → 1 hits; best safe-looking threshold on dev was 0.68 (22 hits, but 2 false). Learning: paraphrases (especially romanised Hinglish) score lower than people expect.
  2. Added 2 extra phrasings per FAQ (variants), checked by script that none equals a test question (no leakage).
  3. Compared 4 models with phrasings off/on (Step 15) → chose paraphrase-multilingual-mpnet-base-v2 + phrasings, T = 0.83 (20 correct, 0 false). Changed the defaults in config.py, .env.example and Dockerfile.
  4. The negation guard first blocked a correct answer ("EMI without any interest": "without" counts as a negation) and "no-cost EMI" looked negated: we added the NEGATION_EXCEPTIONS list. "without" is still a negation word: a trade-off, kept.
  5. The first replay was slower with the cache (996 ms vs 801 ms). Timing every part showed (a) every miss embedded the question twice (lookup and put) and (b) CPU spikes of 200–650 ms right after the CPU had been idle. Fix: lookup() returns the vector and put(vector=…) reuses it, plus a test (test_miss_embeds_the_question_only_once). Using 1 CPU thread instead of 10 did not help, so we did not add it. We also added lookup_ms/llm_ms to every answer so the replay shows where time goes. Clean runs then gave 678–696 ms.
  6. The demo first missed: "Do you deliver on Sundays?" vs its Hinglish version scored 0.665 < 0.83. We measured candidate phrasings and chose the credit-card trio (0.891 / 0.861). We also changed the stand-in LLM from a "word overlap" answer (it picked silly FAQs) to a plainly labelled placeholder.
  7. The first cache hit took ~200 ms (cold model). Added a warm-up in factory.py → ~55 ms.
  8. Testing the zip revealed that FAQ_LOG_PATH= (empty) meant the folder "." and crashed: added the _empty_means_none validator + test_config.py.
  9. Writing this page found one more flaw: rebuilding the project in page order showed a bot's first answer timed together with the one-time FAQ seeding (an exact hit reported 1307 ms; faqcache ask 804 ms). Fix: build_bot() now seeds the default tenant before returning. The project and its zip were updated, and the checkpoints were run again.
  10. Small test fixes: the greeting regex needed [Hh]i (capital "Hi"), and __test__ = False stopped pytest from treating TestItem as a test class.

What we chose NOT to do (and why)

  • Chroma: FAISS + a NumPy store already cover local search; one fewer heavy dependency.
  • A real LLM in the measurements: no key on the build machine; the stand-in is labelled everywhere.
  • Tuning threshold on all 100 questions: that grades our own exam; we used a dev/test split instead.
  • A cross-encoder re-ranker, entity guard, per-category thresholds: good next steps, listed as stretch goals, not built, to keep the project a 3-day project.
  • GPU, Redis in production, Docker build, GitHub push: templates only on this machine.

27 Interview Questions (With Answers)

A. Basics

Q: What is a semantic cache?

A cache whose key is the meaning of a question (an embedding), not its exact text, so paraphrases reuse a saved answer.

Q: Why not an exact-match cache?

People rarely type the same sentence twice: our exact cache hit 0 of 100 questions; the semantic cache hit 20 with no wrong answers.

Q: What is cosine similarity and why normalise vectors?

The cosine of the angle between two vectors (1 = same direction). With length-1 vectors it equals the dot product, so search is one matrix multiply.

Q: What is a false hit and why is it dangerous?

A saved answer returned for a different question. It is served fast and confidently to everyone who asks something similar.

B. Design

Q: How did you choose the threshold?

Swept 0.50–0.99, picked the value with most hits and zero false hits on a dev half, reported it on a held-out test half.

Q: Why a negation guard? Its cost?

Embeddings place 'cancel' and 'can't cancel' close together. The guard cut false hits 5 → 0; its cost: phrases like 'without interest' can be blocked; we keep an exception list.

Q: What must never be cached?

Answers with personal data (order ids, phones, names), refusals and truncated answers; volatile answers get a TTL.

Q: Why one cache per tenant?

So company A never receives company B's answers (data isolation).

Q: Why is decide() a pure function?

The live cache and the evaluation call the same function, so the reported numbers measure the serving code.

C. Scale and production

Q: What changes at 10 million entries?

Approximate index (HNSW/IVF) with a recall check, a shared store (Redis/RedisVL), batched or GPU embeddings, sharding per tenant.

Q: How do you invalidate answers when a policy changes?

TTL for volatile answers, plus explicit eviction by FAQ id / category when the source changes, and user 👎 feedback.

Q: Your cached run was once slower. Why?

With a 20% hit rate, every miss pays the lookup; the miss path embedded twice and the CPU had spikes. We fixed the double embedding and measured a breakdown.

Q: How would you raise recall without false hits?

Better multilingual model, more curated phrasings, a cross-encoder re-ranker on the top-3, per-category thresholds.

29 FAQ

Do I need an API key?

No. Everything runs offline with the stand-in LLM. Add a key only for real-LLM numbers.

Can I use only English?

Yes: use --model sentence-transformers/all-MiniLM-L6-v2 (small, fast), then re-run eval and set your own threshold.

Why is my threshold different?

Different model, data or library version. The threshold is measured, never copied.

Can I use Chroma instead of FAISS?

Yes: write a new store with the same five methods and add it to build_store().

Why commit the reports folder?

So the README can point to the exact files its numbers come from.

Is the stand-in LLM cheating?

No, as long as you label it: it isolates the cache's effect. Report real-LLM numbers separately.

31 Quick Quiz 🎯

Q1: Why do we normalise embeddings to length 1?

So the dot product equals the cosine similarity and search is a single matrix multiply.

Q2: A question contains 'ORD-123456'. What happens?

It skips the cache, goes to the LLM, and its answer is never stored; the log masks it as [order_id].

Q3: What does fall-through do?

If the best candidate is blocked by the negation guard, the next candidate above T may still be used.

Q4: Why tune on dev and report on test?

To avoid grading our own exam; the test half shows how the threshold works on unseen questions.

Q5: Why did the cached replay once get slower?

Most questions still missed, every miss paid the lookup, and the miss path embedded twice; CPU spikes added more.

Q6: Which answers get a 7-day TTL?

Ones whose question or answer mentions prices, fees, charges, offers, coupons, EMI or policies.
