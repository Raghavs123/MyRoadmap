2 How It Works: the Agent Loop and One Server, Any Client

A power socket. MCP is the socket shape: once your tools fit it, any device (Claude Desktop, an IDE, your own agent) can plug in, and you never rewire the house.
Fig 1 — The agent loop: the model sees the server's tools, asks for tool calls, the agent runs them through MCP, and repeats until the model answers (at most 5 times).
  1. The agent starts the MCP server as a child process and asks it: which tools do you have? (list_tools).
  2. It sends your question plus those tool definitions to the model.
  3. The model either answers, or asks for a tool call (name + arguments).
  4. The agent runs the call through MCP (call_tool), adds the result to the conversation and asks the model again.
  5. It stops when the model answers, or after 5 model calls (a hard stop, so it can never loop forever).
Fig 2 — One server, any client: the same server.py works with every MCP client, with no code change. Solid arrows were run for this page; dashed ones are your step.

The brief's real test of understanding: the same server, unchanged, works in every MCP client. On this page three different clients were really run against it; Claude Desktop is the fourth, and it is your step (it was not installed on the build machine).

Fig 3 — The modules. The tools never import the agent, and the agent never imports the tools: they meet only through the MCP protocol.

src/mcpagent/tools.py
"""The three tools as plain Python functions, so they can be tested without MCP or an LLM.

server.py wraps them as MCP tools. Each function returns a string, because that is what
a model reads back.
"""

from __future__ import annotations

import os
import re
from pathlib import Path

import httpx

GITHUB_RAW = "https://raw.githubusercontent.com"
MAX_CHARS = 6000  # a long README would fill the model's context: send the first 6000 characters
MAX_HITS = 15
REPO_RE = re.compile(r"^[A-Za-z0-9_.-]+/[A-Za-z0-9_.-]+$")
SLUG_RE = re.compile(r"[^a-z0-9-]+")


def notes_dir() -> Path:
    """Folder of markdown notes. MCP_NOTES_DIR lets the evaluation use a throw-away copy."""
    default = Path(__file__).resolve().parents[2] / "notes"
    return Path(os.environ.get("MCP_NOTES_DIR") or default)


def search_mode() -> str:
    """'phrase' = v1, the brief's rule: a line must contain the whole query.
    'words'  = v2: every query word of 3+ letters scores a point when it appears in the line or
               in the note's file name; lines are returned best first.
    v2 was added after the first measurement: models searched for 'rag chunk size' or
    'MCP server', phrases that never appear word for word in the notes."""
    return os.environ.get("MCP_SEARCH_MODE", "words")


def _stem(word: str) -> str:
    return word[:-1] if len(word) > 3 and word.endswith("s") else word  # servers -> server


def search_notes(query: str, folder: Path | None = None, mode: str | None = None) -> str:
    """Lines of the notes that match the query (case-insensitive), with file names."""
    folder = folder or notes_dir()
    mode = mode or search_mode()
    q = query.lower().strip()
    words = {_stem(w) for w in re.findall(r"[a-z0-9]+", q) if len(w) >= 3} if mode == "words" else set()
    scored = []
    for f in sorted(folder.glob("*.md")):
        for n, line in enumerate(f.read_text(encoding="utf-8").splitlines()):
            if mode == "words" and (not line.strip() or line.startswith("#")):
                continue  # v2 skips headings: they match the file-name point on every query
            low = line.lower()
            whole = bool(q) and q in low
            points = sum(1 for w in words if w in low or w in f.stem.lower())
            if whole or points:
                scored.append((-(points + 10 * whole), f.name, n, f"{f.name}: {line.strip()}"))
    scored.sort()  # best first; ties keep file and line order
    return "\n".join(hit for *_, hit in scored[:MAX_HITS]) or "No matches."


def read_github_file(repo: str, path: str = "README.md", client: httpx.Client | None = None) -> str:
    """First 6000 characters of a file in a public GitHub repo, e.g. repo='rasbt/LLMs-from-scratch'."""
    repo, path = repo.strip(), path.strip().lstrip("/")
    if not REPO_RE.match(repo):
        return "Error: repo must look like 'owner/name'."
    if ".." in path.split("/"):
        return "Error: path must not contain '..'."
    url = f"{GITHUB_RAW}/{repo}/HEAD/{path}"
    try:
        if client is None:
            r = httpx.get(url, timeout=15, follow_redirects=True)
        else:
            r = client.get(url)
    except httpx.HTTPError as e:
        return f"Error: {type(e).__name__}"
    return r.text[:MAX_CHARS] if r.status_code == 200 else f"Error {r.status_code}"


def write_note(title: str, text: str, folder: Path | None = None) -> str:
    """Save a new markdown note. Never overwrites an existing note, never leaves the notes folder."""
    folder = folder or notes_dir()
    slug = SLUG_RE.sub("-", title.lower()).strip("-")[:60]
    if not slug:
        return "Error: the title needs at least one letter or digit."
    if len(text) > 5000:
        return "Error: the note is longer than 5000 characters."
    target = folder / f"{slug}.md"
    if target.exists():
        return f"Error: a note called {target.name} already exists."
    folder.mkdir(parents=True, exist_ok=True)
    target.write_bytes(f"# {title.strip()}\n\n{text.strip()}\n".encode())
    return f"Saved {target.name}."

"""A second, completely different MCP client: plain JSON-RPC over stdio, no MCP SDK at all.

MCP's stdio transport is simply one JSON message per line on the server's stdin/stdout.
If this hand-written client can list and call our tools, the server speaks the standard
protocol, not something private to our agent. (Claude Desktop is a third client: see README.)
"""

from __future__ import annotations

import json
import subprocess
import sys
from pathlib import Path

PROTOCOL_VERSION = "2025-06-18"  # the client proposes a version; the server answers with its own


class RawStdioClient:
    def __init__(self, server: Path, env: dict | None = None) -> None:
        self.proc = subprocess.Popen(
            [sys.executable, str(server)],
            stdin=subprocess.PIPE,
            stdout=subprocess.PIPE,
            stderr=subprocess.DEVNULL,  # the server logs there; stdout is only for the protocol
            text=True,
            encoding="utf-8",
            env=env,
        )
        self._id = 0

    def request(self, method: str, params: dict | None = None) -> dict:
        self._id += 1
        self._send({"jsonrpc": "2.0", "id": self._id, "method": method, "params": params or {}})
        while True:  # skip notifications until our answer arrives
            msg = json.loads(self.proc.stdout.readline())
            if msg.get("id") == self._id:
                if "error" in msg:
                    raise RuntimeError(msg["error"])
                return msg["result"]

    def notify(self, method: str) -> None:
        self._send({"jsonrpc": "2.0", "method": method})

    def _send(self, msg: dict) -> None:
        self.proc.stdin.write(json.dumps(msg) + "\n")
        self.proc.stdin.flush()

    def close(self) -> None:
        self.proc.stdin.close()
        self.proc.wait(timeout=10)


def handshake_and_call(server: Path, tool: str, arguments: dict, env: dict | None = None) -> dict:
    c = RawStdioClient(server, env)
    try:
        init = c.request(
            "initialize",
            {
                "protocolVersion": PROTOCOL_VERSION,
                "capabilities": {},
                "clientInfo": {"name": "raw-json-client", "version": "0.1"},
            },
        )
        c.notify("notifications/initialized")
        listed = c.request("tools/list")
        called = c.request("tools/call", {"name": tool, "arguments": arguments})
    finally:
        c.close()
    return {
        "server": init["serverInfo"],
        "protocolVersion": init["protocolVersion"],
        "tools": [t["name"] for t in listed["tools"]],
        "call": called["content"][0]["text"],
    }

"""One small interface for every model: chat(messages, tools) -> ChatResult.

Messages and tools use the OpenAI chat format (Gemini's OpenAI-compatible endpoint speaks it,
and the local Qwen chat template understands it too), so the agent loop never changes.
"""

from __future__ import annotations

import json
from dataclasses import dataclass, field
from typing import Protocol


@dataclass(frozen=True)
class ToolCall:
    id: str
    name: str
    arguments: dict  # already parsed from JSON; {} if the model sent invalid JSON
    raw_arguments: str = ""  # what the model really sent, kept for debugging


@dataclass(frozen=True)
class ChatResult:
    content: str
    tool_calls: list[ToolCall] = field(default_factory=list)
    input_tokens: int = 0
    output_tokens: int = 0
    seconds: float = 0.0

    def as_message(self) -> dict:
        """The assistant turn to append to the history (OpenAI format)."""
        msg: dict = {"role": "assistant", "content": self.content or ""}
        if self.tool_calls:
            msg["tool_calls"] = [
                {
                    "id": c.id,
                    "type": "function",
                    "function": {"name": c.name, "arguments": json.dumps(c.arguments)},
                }
                for c in self.tool_calls
            ]
        return msg


class ChatModel(Protocol):
    name: str

    def chat(self, messages: list[dict], tools: list[dict]) -> ChatResult: ...


def parse_arguments(text: str) -> dict:
    try:
        value = json.loads(text or "{}")
    except json.JSONDecodeError:
        return {}
    return value if isinstance(value, dict) else {}

"""Open Qwen2.5 models on your own computer, with real tool calling (no key, no quota).

Qwen2.5's chat template understands OpenAI-style tool definitions: the model answers with
<tool_call>{"name": ..., "arguments": {...}}</tool_call> blocks, which we parse into ToolCalls.
Greedy decoding: the same input always gives the same output.

The first run downloads the model (0.5B ~1 GB, 3B ~6 GB). Set HF_HOME to a disk with space.
Device: MCP_AGENT_DEVICE = cpu | cuda | auto (default auto: the GPU if PyTorch can see one).
Number format: float16 on a GPU; float32 on a CPU (the agent's prompts are long, and on a laptop
CPU without fast 16-bit maths, reading a long prompt was ~5x faster in float32).
"""

from __future__ import annotations

import json
import os
import re
import time

from mcpagent.llm.base import ChatResult, ToolCall

TOOL_CALL_RE = re.compile(r"<tool_call>\s*(\{.*?\})\s*</tool_call>", re.S)
SMALL, BIG = "Qwen/Qwen2.5-0.5B-Instruct", "Qwen/Qwen2.5-3B-Instruct"


class LocalModel:
    def __init__(
        self, name: str = BIG, dtype: str | None = None, device: str | None = None, max_new_tokens: int = 384
    ) -> None:
        import torch
        from transformers import AutoModelForCausalLM, AutoTokenizer

        threads = os.environ.get("MCP_AGENT_THREADS")
        if threads:
            torch.set_num_threads(int(threads))
        self.name = name
        self.max_new_tokens = max_new_tokens
        self._torch = torch
        self.tokenizer = AutoTokenizer.from_pretrained(name)
        device = device or os.environ.get("MCP_AGENT_DEVICE", "auto")
        if device == "auto":
            device = "cuda" if torch.cuda.is_available() else "cpu"
        self.device = device
        dtype = dtype or os.environ.get("MCP_AGENT_DTYPE") or ("float16" if device == "cuda" else "float32")
        self.model = AutoModelForCausalLM.from_pretrained(name, dtype=getattr(torch, dtype)).to(device).eval()
        self.chat([{"role": "user", "content": "Say OK."}], [])  # untimed warm-up

    def chat(self, messages: list[dict], tools: list[dict]) -> ChatResult:
        start = time.perf_counter()
        ids = self.tokenizer.apply_chat_template(
            _for_template(messages),
            tools=tools or None,
            add_generation_prompt=True,
            return_tensors="pt",
            return_dict=True,
        ).to(self.device)
        with self._torch.inference_mode():
            out = self.model.generate(
                **ids,
                max_new_tokens=self.max_new_tokens,
                do_sample=False,
                temperature=None,
                top_p=None,
                top_k=None,
                pad_token_id=self.tokenizer.eos_token_id,
            )
        new = out[0, ids["input_ids"].shape[1] :]
        text = self.tokenizer.decode(new, skip_special_tokens=True).strip()
        calls, content = parse_tool_calls(text)
        return ChatResult(
            content=content,
            tool_calls=calls,
            input_tokens=int(ids["input_ids"].shape[1]),
            output_tokens=int(len(new)),
            seconds=self._elapsed(start),
        )

    def _elapsed(self, start: float) -> float:
        if self.device == "cuda":
            self._torch.cuda.synchronize()  # GPU work is asynchronous: wait before reading the clock
        return time.perf_counter() - start


def parse_tool_calls(text: str) -> tuple[list[ToolCall], str]:
    """Split a Qwen reply into tool calls and the remaining plain text."""
    calls = []
    for n, block in enumerate(TOOL_CALL_RE.findall(text), start=1):
        try:
            obj = json.loads(block)
        except json.JSONDecodeError:
            continue
        args = obj.get("arguments", {})
        if isinstance(args, str):
            try:
                args = json.loads(args)
            except json.JSONDecodeError:
                args = {}
        if isinstance(obj.get("name"), str):
            calls.append(ToolCall(id=f"call_{n}", name=obj["name"], arguments=args, raw_arguments=block))
    return calls, TOOL_CALL_RE.sub("", text).strip()


def _for_template(messages: list[dict]) -> list[dict]:
    """The Qwen template wants tool-call arguments as a dict, not a JSON string."""
    out = []
    for m in messages:
        if m.get("tool_calls"):
            m = {
                **m,
                "tool_calls": [
                    {
                        "type": "function",
                        "function": {
                            "name": c["function"]["name"],
                            "arguments": json.loads(c["function"]["arguments"] or "{}"),
                        },
                    }
                    for c in m["tool_calls"]
                ],
            }
        out.append(m)
    return out

    res = AgentResult(answer="")
    for _ in range(MAX_STEPS):
        reply = model.chat(messages, functions)
        res.steps += 1
        res.llm_seconds += reply.seconds
        res.input_tokens += reply.input_tokens
        res.output_tokens += reply.output_tokens
        if not reply.tool_calls:
            res.answer = reply.content
            break
        messages.append(reply.as_message())
        for call in reply.tool_calls:
            t = time.perf_counter()
            out = await session.call_tool(call.name, call.arguments)
            text = out.content[0].text if out.content else ""
            res.tool_seconds += time.perf_counter() - t
            res.tools_used.append(ToolUse(call.name, call.arguments, time.perf_counter() - t, text[:200]))
            messages.append({"role": "tool", "tool_call_id": call.id, "content": text})
    else:
        res.answer, res.stopped = f"Stopped after {MAX_STEPS} steps.", True
    res.seconds = time.perf_counter() - start
    return res


async def ask(question: str, model: ChatModel, notes_dir: Path | None = None) -> AgentResult:
    """One question with a freshly started server (the brief's agent.py does exactly this)."""
    async with stdio_client(server_params(notes_dir)) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()
            return await run_agent(question, model, session)

"""Measure the agent on tasks.jsonl: did it pick the right tool, and was the answer correct?

* right tool (first)  - the FIRST tool the model called is the expected one (strict)
* right tool (any)    - the expected tool was called at some point (lenient)
* answer correct      - automatic check: the answer contains one of the expected strings,
                        or (write tasks) the note file really exists and contains the text.

Every task result is saved to results/<label>.json as soon as it is done, so a run that hits
a free-tier limit can simply be started again: finished tasks are skipped.
The notes folder is copied to a temporary folder first, so write_note never changes notes/.
"""

from __future__ import annotations

import json
import shutil
import tempfile
import time
from pathlib import Path

from mcp import ClientSession
from mcp.client.stdio import stdio_client

from mcpagent.agent import ROOT, run_agent, server_params
from mcpagent.llm.base import ChatModel
from mcpagent.tools import SLUG_RE, write_note


def load_tasks(path: Path) -> list[dict]:
    tasks = [json.loads(line) for line in Path(path).read_text(encoding="utf-8").splitlines() if line.strip()]
    ids = [t["id"] for t in tasks]
    if len(ids) != len(set(ids)):
        raise ValueError("duplicate task ids")
    return tasks


def check_answer(task: dict, answer: str, notes_dir: Path) -> bool:
    if "note_contains" in task:
        want = task["note_contains"]
        f = notes_dir / (SLUG_RE.sub("-", want["title"].lower()).strip("-") + ".md")
        return f.exists() and want["text"].lower() in f.read_text(encoding="utf-8").lower()
    return any(s.lower() in (answer or "").lower() for s in task["answer_contains_any"])


def score(task: dict, result: dict, notes_dir: Path) -> dict:
    names = [t["name"] for t in result["tools_used"]]
    return {
        "right_tool_first": bool(names) and names[0] == task["tool"],
        "right_tool_any": task["tool"] in names,
        "answer_correct": check_answer(task, result["answer"], notes_dir),
        "tools_called": names,
    }


def load_results(path: Path) -> dict:
    return json.loads(Path(path).read_text(encoding="utf-8")) if Path(path).exists() else {}


def save_results(path: Path, data: dict) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_suffix(".tmp")
    tmp.write_bytes((json.dumps(data, indent=1, ensure_ascii=False) + "\n").encode("utf-8"))
    tmp.replace(path)


async def run_eval(model: ChatModel, tasks: list[dict], out: Path, sleep_s: float = 0.0, log=print) -> dict:
    data = load_results(out)
    todo = [t for t in tasks if t["id"] not in data]
    log(f"{out.name}: {len(data)} done, {len(todo)} to run")
    if not todo:
        return data
    with tempfile.TemporaryDirectory() as tmp:
        notes = Path(tmp) / "notes"
        shutil.copytree(ROOT / "notes", notes)
        for t in data.values():  # notes written by an earlier (resumed) run
            for use in t["result"]["tools_used"]:
                if use["name"] == "write_note":
                    write_note(use["arguments"].get("title", ""), use["arguments"].get("text", ""), notes)
        async with stdio_client(server_params(notes)) as (read, write):
            async with ClientSession(read, write) as session:
                await session.initialize()
                for task in todo:
                    result = (await run_agent(task["question"], model, session)).to_dict()
                    data[task["id"]] = {"task": task, "result": result, **score(task, result, notes)}
                    save_results(out, data)
                    s = data[task["id"]]
                    log(
                        f"  {task['id']:3s} tools={s['tools_called']} first_ok={s['right_tool_first']} "
                        f"answer_ok={s['answer_correct']} {result['seconds']:.1f}s"
                    )
                    if sleep_s:
                        time.sleep(sleep_s)  # free-tier rate limit; not part of the measured time
    return data


def summarize(label: str, data: dict, tasks: list[dict]) -> dict:
    rows = [data[t["id"]] for t in tasks if t["id"] in data]
    n = len(rows)

    def mean(key):
        return round(sum(r["result"][key] for r in rows) / n, 2) if n else 0.0

    by_tool = {}
    for r in rows:
        tool = r["task"]["tool"]
        ok, tot = by_tool.get(tool, (0, 0))
        by_tool[tool] = (ok + r["right_tool_first"], tot + 1)
    return {
        "label": label,
        "n": n,
        "right_tool_first": sum(r["right_tool_first"] for r in rows),
        "right_tool_any": sum(r["right_tool_any"] for r in rows),
        "answer_correct": sum(r["answer_correct"] for r in rows),
        "stopped": sum(r["result"]["stopped"] for r in rows),
        "avg_steps": mean("steps"),
        "avg_seconds": mean("seconds"),
        "avg_llm_seconds": mean("llm_seconds"),
        "avg_tool_seconds": mean("tool_seconds"),
        "avg_input_tokens": mean("input_tokens"),
        "by_tool": {k: f"{v[0]}/{v[1]}" for k, v in sorted(by_tool.items())},
    }

from __future__ import annotations

import json
from pathlib import Path

from mcpagent.evaluation import load_results, load_tasks, summarize


def write_report(root: Path) -> tuple[Path, list[dict]]:
    tasks = load_tasks(root / "tasks.jsonl")
    rows, per_task = [], {}
    for f in sorted((root / "results").glob("*.json")):
        data = load_results(f)
        rows.append(summarize(f.stem, data, tasks))
        per_task[f.stem] = data
    lines = [
        "# Results",
        "",
        "Generated by `mcpagent report` from `results/*.json`. Do not edit by hand.",
        "",
        "| Run (provider__model__search) | Right tool (first call) | Right tool (any call) "
        "| Answer correct | Stopped at 5 steps | Avg steps | Avg time | Model time | Tool time |",
        "|---|---|---|---|---|---|---|---|---|",
    ]
    for r in rows:
        lines.append(
            f"| {r['label']} | {r['right_tool_first']}/{r['n']} | {r['right_tool_any']}/{r['n']} "
            f"| {r['answer_correct']}/{r['n']} | {r['stopped']} | {r['avg_steps']} "
            f"| {r['avg_seconds']} s | {r['avg_llm_seconds']} s | {r['avg_tool_seconds']} s |"
        )
    lines += ["", "## Per task", ""]
    head = "| Task | Expected tool | " + " | ".join(r["label"] for r in rows) + " |"
    lines += [head, "|" + "---|" * (2 + len(rows))]
    for t in tasks:
        cells = []
        for r in rows:
            d = per_task[r["label"]].get(t["id"])
            if d is None:
                cells.append("-")
                continue
            tools = ",".join(d["tools_called"]) or "(none)"
            cells.append(f"{'✅' if d['answer_correct'] else '❌'} {tools}")
        lines.append(f"| {t['id']} | {t['tool']} | " + " | ".join(cells) + " |")
    lines += [
        "",
        "Right tool (first call) = the first tool the model called is the expected one. "
        "Answer correct = automatic check (expected text in the answer, or the note file really "
        "written). Times are wall clock on the machine that ran the evaluation.",
        "",
    ]
    out = root / "reports" / "RESULTS.md"
    out.parent.mkdir(parents=True, exist_ok=True)
    out.write_bytes("\n".join(lines).encode("utf-8"))
    (root / "reports" / "summary.json").write_bytes((json.dumps(rows, indent=1) + "\n").encode("utf-8"))
    return out, rows

    """Run label, e.g. local-cuda__qwen2.5-3b-instruct__search-words. CPU and GPU never mix."""

    import socket
    import subprocess
    import sys
    import time

    from mcp import ClientSession
    from mcp.client.streamable_http import streamable_http_client

    with socket.socket() as s:
        s.bind(("127.0.0.1", 0))
        port = s.getsockname()[1]
    env = dict(os.environ, MCP_NOTES_DIR=str(tmp_path))
    (tmp_path / "x.md").write_text("- streamable HTTP for remote servers\n", encoding="utf-8")

        env=env,
        stdout=subprocess.DEVNULL,
        stderr=subprocess.DEVNULL,
    )

    async def run():
        async with streamable_http_client(f"http://127.0.0.1:{port}/mcp") as (read, write, _):
            async with ClientSession(read, write) as session:
                await session.initialize()
                names = [t.name for t in (await session.list_tools()).tools]
                out = await session.call_tool("search_notes", {"query": "remote"})
                return names, out.content[0].text

    try:
        for _ in range(100):  # wait until the port answers
            with socket.socket() as s:
                if s.connect_ex(("127.0.0.1", port)) == 0:
                    break
            time.sleep(0.1)
        names, text = asyncio.run(run())
    finally:
        srv.terminate()
        srv.wait(timeout=10)

"""Turn reports/demo_output.txt into docs/demo.gif (a ~20-second terminal animation).

    pip install -e ".[demo]"      (Pillow)
    python scripts/make_demo_gif.py

Commands are "typed" letter by letter, outputs appear line by line. The text is the real
saved output of scripts/record_demo.py; the GIF only animates it (not a screen capture).
"""

from __future__ import annotations

import sys
import textwrap
from pathlib import Path

from PIL import Image, ImageDraw, ImageFont

ROOT = Path(__file__).resolve().parent.parent
WIDTH, HEIGHT, PAD, COLS = 960, 400, 18, 86
BG, FG, CMD, DIM = (24, 26, 33), (220, 223, 228), (126, 231, 135), (139, 148, 158)


def font(size: int = 16):
    for name in ("consola.ttf", "DejaVuSansMono.ttf", "Menlo.ttc"):
        try:
            return ImageFont.truetype(name, size)
        except OSError:
            continue
    return ImageFont.load_default(size=size)


def frame(lines: list[tuple[str, tuple]], fnt, line_h: int) -> Image.Image:
    img = Image.new("RGB", (WIDTH, HEIGHT), BG)
    d = ImageDraw.Draw(img)
    for i, color in enumerate([(255, 95, 86), (255, 189, 46), (39, 201, 63)]):  # window dots
        d.ellipse((PAD + i * 22, 10, PAD + i * 22 + 12, 22), fill=color)
    visible = lines[-((HEIGHT - 40) // line_h) :]
    for i, (text, color) in enumerate(visible):
        d.text((PAD, 34 + i * line_h), text, font=fnt, fill=color)
    return img


def main() -> int:
    src = ROOT / "reports" / "demo_output.txt"
    raw = src.read_text(encoding="utf-8").splitlines()
    fnt, line_h = font(16), 21
    frames, durations, shown = [], [], []
    for line in raw:
        if line.startswith("$ "):
            for n in range(2, len(line) + 1, 3):  # type the command, 3 letters per frame
                frames.append(frame([*shown, (line[:n] + "_", CMD)], fnt, line_h))
                durations.append(60)
            shown.append((line, CMD))
            frames.append(frame(shown, fnt, line_h))
            durations.append(1300)  # "thinking"
            continue
        for part in textwrap.wrap(line, COLS) or [""]:
            shown.append((part, DIM if part.startswith(("tool", "time")) else FG))
            frames.append(frame(shown, fnt, line_h))
            durations.append(750)
    durations[-1] = 5000  # hold the last frame
    out = ROOT / "docs" / "demo.gif"
    out.parent.mkdir(exist_ok=True)
    frames[0].save(out, save_all=True, append_images=frames[1:], duration=durations, loop=0)
    print(f"wrote {out}: {len(frames)} frames, {sum(durations) / 1000:.1f} s")
    return 0


if __name__ == "__main__":
    sys.exit(main())

| v2 | `search_notes` = ranked word match (+ file name, + plural) | 14/15 / 11/15 | 10/15 / 7/15 |

What failed, in the order we found it:

1. **The brief's search tool, not the model, was the bottleneck.** Both models picked `search_notes` for the notes
   questions, but searched for phrases like "rag chunk size", "MCP server transports" or "Chinook database tables".
   No note contains those words in that order, so the whole-phrase match returned "No matches." every time and the
   3B model answered 0 of the 7 notes questions. The v2 rule gives a point for each query word found in a line or in
   the note's file name ("rag" is only in `rag.md`) and returns the best lines first. That raised the 3B model from
   5/15 to 11/15 correct, with the same tool choices. *Honest caveat: v2 was designed after looking at the failed
   queries of these same 15 tasks; the rule is generic (no task-specific words), but a fresh task set would be the
   fair test.*
2. **Invented file paths.** Asked for the ISBN, the 3B model called `read_github_file` with
   `path="content/file_with_isbn.txt"`, got "Error 404" and gave up instead of reading `README.md` (where the ISBN
   is). Same for chapter 4 (`path="chapter_4"`). A better tool description is the next step (not tuned here).
3. **The small model often describes a tool call instead of making one** ("I can use the search_notes tool. Could you
   please provide the query?"): 5 of 15 tasks with no tool call at all, in every run. Better tools cannot fix that;
   a bigger model or a stricter system prompt might.
4. **A hallucination worth knowing:** without calling a tool, the 0.5B model stated the nanoGPT context size as 128
   (the README says 256). Once, the 3B model searched a GitHub repo it invented. Always check answers against sources.
5. **CPU vs GPU.** The first runs used the laptop CPU: 30 s per task for 0.5B and 80 s for 3B. The same runs on the
   RTX 5050 (float16) took 4.8 s and 14.2 s, with exactly the same scores. The GPU made re-running cheap, which is
   what made trying an improvement practical.

2. Better tool descriptions: "path defaults to README.md, read it first", because a model invented a file path and gave up

23 Interview Questions (With Answers)

A. MCP basics

Q: What is MCP?

The Model Context Protocol: an open standard for connecting LLM applications to tools and data. A server exposes tools, resources and prompts; any MCP client can use them.

Q: Host, client, server?

The host is the app (Claude Desktop, your agent); it creates one client per server; the server exposes the tools. Our agent is host and client in one.

Q: Which transports did you use?

stdio (the client starts the server as a child process; one JSON message per line) and streamable HTTP (for remote servers). Both were tested.

Q: Why never print() in a stdio server?

stdout carries the protocol messages; any extra text breaks the JSON stream. Log to stderr.

B. The agent

Q: How does the model know the tools?

The agent calls list_tools and turns each tool's name, description and JSON schema into a function definition for the model. The docstring is the description, so it must be written for a model.

Q: How do you stop an agent from looping?

A hard limit of 5 model calls, plus a result flag (stopped) that the evaluation counts.

Q: How did you prove 'any client'?

Three different clients really ran against the unchanged server: the SDK over stdio, a hand-written JSON-RPC client with no SDK, and the SDK over streamable HTTP. Claude Desktop is the fourth.

C. Measurement

Q: What did you measure?

Two numbers on 15 labelled tasks: right tool on the first call, and a correct final answer (automatic check, plus reading all answers by hand: 89/90 agreement).

Q: What was your biggest finding?

Tool choice was already good (14/15), but answers were poor (5/15) because the brief's search tool matched only whole phrases. Fixing the tool, not the model, raised it to 11/15.

Q: Is 11/15 trustworthy?

It is honest but optimistic: the search fix was designed after seeing failures on the same 15 tasks, and 15 tasks is small (one task = 7%). A fresh task set is the fair test.

Q: Why run on a GPU?

Same scores, about 5.6x faster for the 3B model, which made re-running after each change cheap.

24 Mini Glossary

MCP
Model Context Protocol: a standard way for LLM apps to use tools and data.
MCP server
A program that exposes tools (and resources, prompts) over MCP.
MCP client / host
The side that connects to a server / the app that owns the clients.
Tool
A function the model may call, with a name, a description and an input schema.
Tool calling
The model replies with a tool name and arguments instead of text.
stdio transport
Server started as a child process; messages are lines on stdin/stdout.
Streamable HTTP
MCP over HTTP, for remote servers.
JSON-RPC
The message format MCP uses: method, params, id, result or error.
FastMCP
The high-level server class in MCP Python SDK 1.x (MCPServer in 2.x).
Agent loop
Model → tool calls → results → model, until it answers or hits a limit.
Right tool (first call)
The first tool the model picked is the expected one.
float16 / float32
16-bit / 32-bit numbers; GPUs are fast with 16-bit.

25 FAQ

Do I need a GPU?

No. With Gemini the model runs at Google. The GPU only speeds up the free local models.

Is the Gemini free tier enough?

For 15 tasks × 2 models × a few model calls, yes; set MCP_AGENT_SLEEP_S and re-run if you hit a limit (finished tasks are skipped). Use sample data only: free-tier prompts may be used to improve Google's products.

Why local Qwen numbers instead of Gemini?

No Gemini key existed on the build machine. The code is identical; only the model changes.

Can I add more tools?

Yes: write a function in tools.py, wrap it with @mcp.tool() in server.py, add tasks for it. The agent picks it up automatically.

Why is search_notes so simple?

With 8 notes, ranked word matching is enough and easy to explain. With hundreds, use BM25 or embeddings.
