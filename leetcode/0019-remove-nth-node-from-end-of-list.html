You are given the head of a singly linked list. Remove the n-th node counted from the end of the list (the last node is number 1) and return the head of the changed list.

2 💡 Examples and Constraints

Example 1

Input: head = [1,2,3,4,5], n = 2
Output: [1,2,3,5]
Explanation: Counting from the end, node 4 is number 2 (node 5 is number 1). Removing it leaves 1, 2, 3, 5.

Example 2

Input: head = [1], n = 1
Output: []
Explanation: The only node is also the last one, so removing it leaves an empty list.

Example 3

Input: head = [1,2], n = 1
Output: [1]
Explanation: The last node (2) is removed.

📖 Example breakdown (Example 1), step by step
  • The list is 1 → 2 → 3 → 4 → 5 and we must remove the 2nd node from the end.
  • Counting from the end: 5 is number 1 and 4 is number 2, so the node with value 4 must go.
  • The node before it is the node with value 3. Make 3 point to 5 instead of 4.
  • The list is now 1 → 2 → 3 → 5.
  • Result: [1,2,3,5] ✅ (the expected output of Example 1)

⚠️ Constraints

  • The number of nodes in the list is sz.
  • 1 <= sz <= 30
  • 0 <= Node.val <= 100
  • 1 <= n <= sz
Follow-up: Could you do this in one pass over the list?

3 🧠 How to Think About It (in Easy Words)

A linked list only knows 'what comes next', so counting from the end is awkward. Two easy ideas: first walk the list once to count the nodes (then the node to delete is number length - n from the front), or use two pointers with a gap of n nodes: when the front pointer reaches the end, the back pointer is exactly in front of the node to delete. In both cases a small helper node placed before the head (a dummy node) makes deleting the very first node just like deleting any other node.

Below you will find 3 approaches, from the simplest (brute force) to the best. Each one has the idea in plain words, its speed and memory cost, the code in C++, Java and Python (click the tabs; your choice is remembered), and a step-by-step dry run on a small input.

4 🚀 Approach 1: Two Passes: Count the Length, Then Walk

Brute force

💡 Intuition

Pass one: count the nodes (length). Put a dummy node in front of the head. Pass two: walk length - n steps from the dummy; you stand on the node just before the one to delete. Skip over the unwanted node with cur.next = cur.next.next.

First count the carriages of a train, then walk to the right one from the front and unhook the next carriage.

🪜 Algorithm, Step by Step

  1. Make a dummy node that points to the head.
  2. Pass 1: count the nodes: length.
  3. Pass 2: start at the dummy and move length - n steps; now you stand just before the node to delete.
  4. Set cur.next = cur.next.next and return dummy.next.

⏱️ Complexity

CostWhy
TimeO(sz)one pass to count and at most one more pass to walk
SpaceO(1)only a few pointers
Good sideWeak side
Easy to understand and to get right.Goes over the list twice; the follow-up asks for one pass.

💻 Code

class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode dummy(0, head);                               // a helper node before the head
        int length = 0;
        for (ListNode* p = head; p; p = p->next) length++;     // pass 1: count the nodes
        ListNode* cur = &dummy;
        for (int i = 0; i < length - n; i++) cur = cur->next;  // pass 2: stand just before the node to delete
        cur->next = cur->next->next;                           // unlink it
        return dummy.next;
    }
};
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {

        for (int i = 0; i < length - n; i++) cur = cur.next;   // pass 2: stand just before the node to delete
        cur.next = cur.next.next;                              // unlink it

}
class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)                       # a helper node before the head
        length = 0
        node = head
        while node:                                     # pass 1: count the nodes
            length += 1

        cur = dummy
        for _ in range(length - n):                     # pass 2: stand just before the node to delete
            cur = cur.next
        cur.next = cur.next.next                        # unlink it
        return dummy.next

5 🚀 Approach 2: One Pass: Two Pointers with a Gap of n (Most Optimized)

Most optimized

💡 Intuition

Start two pointers on the dummy node. Move fast forward n steps, so it is exactly n nodes ahead of slow. Now move both together until fast stands on the last node. At that moment slow is just before the node to delete.

Two runners start with a gap of n metres between them. When the front runner touches the finish line, the back runner stands exactly n metres from it.

🪜 Algorithm, Step by Step

  1. Make a dummy node that points to the head; let fast and slow both start on it.
  2. Move fast forward n steps.
  3. Move fast and slow together until fast.next is empty (fast is on the last node).
  4. slow now stands just before the node to delete: set slow.next = slow.next.next and return dummy.next.

⏱️ Complexity

CostWhy
TimeO(sz)each pointer moves at most the length of the list, in a single pass
SpaceO(1)only a few pointers
Good sideWeak side
A single pass, which answers the follow-up question.The gap idea needs a moment of thought; off-by-one mistakes are easy.

💻 Code

class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode dummy(0, head);                               // a helper node before the head
        ListNode* fast = &dummy;
        ListNode* slow = &dummy;
        for (int i = 0; i < n; i++) fast = fast->next;         // fast is now n nodes ahead of slow
        while (fast->next) {                                   // move together until fast stands on the last node
            fast = fast->next;
            slow = slow->next;
        }
        slow->next = slow->next->next;                         // slow is just before the node to delete
        return dummy.next;
    }
};

    public ListNode removeNthFromEnd(ListNode head, int n) {

            fast = fast.next;
            slow = slow.next;
        }
        slow.next = slow.next.next;                            // slow is just before the node to delete

    }
}

6 🚀 Approach 3: Recursion: Count Back on the Way Home

Optimized (alternative)

💡 Intuition

Walk to the end of the list by recursion. On the way back, each call learns its own position counted from the end (the last node is 1, the one before it is 2, ...). The node whose position is n + 1 is the one just before the target, so it removes its next node. The dummy node has a position too, so removing the head works.

Climb to the top of a tower, then count the steps as you come down.

🪜 Algorithm, Step by Step

  1. Make a dummy node that points to the head.
  2. Call walk(node) recursively down to the end of the list.
  3. On the way back each call computes its own position from the end (fromEnd; the last node is 1).
  4. The call with fromEnd == n + 1 unlinks its next node. Return dummy.next.

⏱️ Complexity

CostWhy
TimeO(sz)every node is visited once on the way down and once on the way back
SpaceO(sz) for the recursionthe recursion stack is as deep as the list is long
Good sideWeak side
One pass and no pointer gap to think about.Uses recursion memory proportional to the list length.

💻 Code

class Solution {
    int walk(ListNode* node, int n) {                          // returns the position of 'node' counted from the end
        if (!node) return 0;                                   // past the end
        int fromEnd = walk(node->next, n) + 1;
        if (fromEnd == n + 1) node->next = node->next->next;   // the next node is the n-th from the end: unlink it
        return fromEnd;
    }
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode dummy(0, head);                               // a helper node before the head
        walk(&dummy, n);
        return dummy.next;
    }
};
class Solution {
    private int walk(ListNode node, int n) {                   // returns the position of 'node' counted from the end
        if (node == null) return 0;                           // past the end
        int fromEnd = walk(node.next, n) + 1;
        if (fromEnd == n + 1) node.next = node.next.next;      // the next node is the n-th from the end: unlink it
        return fromEnd;
    }

    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(0, head);                // a helper node before the head
        walk(dummy, n);
        return dummy.next;
    }
}
class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        def walk(node):                                 # returns the position of 'node' counted from the end
            if not node:
                return 0                                # past the end
            from_end = walk(node.next) + 1
            if from_end == n + 1:
                node.next = node.next.next              # the next node is the n-th from the end: unlink it
            return from_end

        dummy = ListNode(0, head)                       # a helper node before the head
        walk(dummy)
        return dummy.next

8 🔑 Key Insights

  • The n-th node from the end is the (length - n + 1)-th node from the front. For length 5 and n = 2 that is node number 4 (the value 4), and you must stand on node 3, after 5 - 2 = 3 steps from the dummy.
  • A dummy node in front of the head makes removing the first node the same as removing any other node: no special case, and you can always return dummy.next.
  • With a gap of n nodes between two pointers, the back pointer is exactly in the right place when the front pointer reaches the end: one pass instead of two.

10 ⚠️ Common Mistakes

  • Forgetting the dummy node: removing the first node then needs a special case, and many solutions crash or return the wrong head.
  • Off-by-one when walking: you must stop on the node before the one you delete, not on the node itself.
  • Counting from the front instead of the end (n-th from the end is node number length - n + 1 from the front).
  • Moving fast only n - 1 or n + 1 steps before starting the joint walk.
  • Returning head instead of dummy.next: if the head was removed, head still points at the deleted node.
