Medium   Topics: String

Write a function myAtoi(s) that converts a string to a 32-bit signed integer, like the C function atoi. Follow these steps in order:

  1. Whitespace: ignore any leading spaces (only the space character ' ').
  2. Sign: if the next character is '-' or '+', read it. A minus means the result is negative; a plus or no sign means positive.
  3. Digits: read the digits that follow, and stop at the first character that is not a digit (or at the end of the string). Ignore leading zeros. If no digits were read, the result is 0.
  4. Range: if the number is below -231, return -231; if it is above 231 - 1, return 231 - 1.

Return the integer.

2 Examples and Constraints

Example 1

Input: s = "42"
Output: 42
Explanation: No spaces, no sign, digits 4 and 2: the result is 42.

Example 2

Input: s = " -042"
Output: -42
Explanation: Skip the leading space, read the minus sign, read the digits 042 (leading zero ignored): -42.

Example 3

Input: s = "1337c0d3"
Output: 1337
Explanation: Read digits until the first non-digit 'c': 1337.

Example 4

Input: s = "0-1"
Output: 0
Explanation: Read the digit 0, then stop at '-' (a sign is only allowed before the digits): 0.

Example 5

Input: s = "words and 987"
Output: 0
Explanation: The first character is a letter, so no digits can be read: 0.

Constraints

  • 0 <= s.length <= 200
  • s consists of English letters (lower-case and upper-case), digits (0-9), ' ', '+', '-', and '.'.

3 How to Think About It (in Easy Words)

Think of a strict ticket officer. He first ignores people waiting in the queue (spaces). Then he accepts at most one badge (a sign). Then he takes your digits one by one, and the moment you say anything that is not a digit he stops and does not listen any more. If the total is too big for his 32-bit counter he just writes the biggest (or smallest) value the counter can show.

Below you will find 3 approaches, from the simplest (brute force) to the best. Each one has the idea in plain words, its speed and memory cost, the code in C++, Java and Python (click the tabs; your choice is remembered), and a step-by-step dry run on a small input.

4 Approach 1: Brute Force: Cut the Number Out, Then Convert

Brute force

Idea: First find where the number text starts and ends (skip spaces, read an optional sign, collect the digit characters). Then convert that digit text to a number in one go and clamp it to the 32-bit range.

Like cutting the price out of a newspaper advertisement with scissors first, and only then adding it up.
TimeSpaceGood sideWeak side
O(n)O(n)Easy to split into small, clear steps.Builds an extra string; the conversion needs a wider number, and a very long digit text needs special care (here: more than 10 digits is always out of range).

Code

class Solution {
public:
    int myAtoi(string s) {
        int n = s.size(), i = 0;
        while (i < n && s[i] == ' ') i++;                      // step 1: skip leading spaces
        int sign = 1;
        if (i < n && (s[i] == '+' || s[i] == '-')) {           // step 2: optional sign
            if (s[i] == '-') sign = -1;
            i++;
        }
        int start = i;
        while (i < n && s[i] >= '0' && s[i] <= '9') i++;       // step 3: the digits are s[start .. i-1]
        string digits = s.substr(start, i - start);            // cut the number text out
        size_t firstNonZero = digits.find_first_not_of('0');   // ignore leading zeros
        if (firstNonZero == string::npos) return 0;            // no digits at all, or only zeros
        digits = digits.substr(firstNonZero);
        if (digits.size() > 10) return sign == 1 ? INT_MAX : INT_MIN;   // 11 or more digits is always out of range
        long long value = sign * stoll(digits);                // at most 10 digits: fits in 64 bits
        if (value > INT_MAX) return INT_MAX;                   // step 4: clamp to the 32-bit range
        if (value < INT_MIN) return INT_MIN;
        return (int)value;
    }
};

        String digits = s.substring(start, i);                 // cut the number text out

        long value = sign * Long.parseLong(digits);            // at most 10 digits: fits in 64 bits
        if (value > Integer.MAX_VALUE) return Integer.MAX_VALUE;   // step 4: clamp to the 32-bit range
        if (value < Integer.MIN_VALUE) return Integer.MIN_VALUE;
        return (int) value;
    }
}

5 Approach 2: A State Machine (Finite Automaton)

Optimized (clean design)

Idea: Describe the rules as a tiny machine with four states: start, signed, in number, end. For every character, look up the next state in a table (rows = current state, columns = kind of character: space, sign, digit, other). Do the work that belongs to the new state: remember the sign, add a digit, or stop.

Like a turnstile with a few positions: each key press (character) moves it to the next position, and some positions lock it for good.
TimeSpaceGood sideWeak side
O(n)O(1)The rules live in one small table, so changing a rule means changing one number. Great for bigger parsers.More code than needed for this small problem.

Code

class Solution {
    // rows = current state, columns = kind of the next character
    //                    space  sign  digit  other
    int table[4][4] = {{0,     1,    2,     3},     // state 0 = start
                       {3,     3,    2,     3},     // state 1 = signed (a + or - was read)
                       {3,     3,    2,     3},     // state 2 = in number (digits are being read)
                       {3,     3,    3,     3}};    // state 3 = end (stop reading)
    int kind(char c) {
        if (c == ' ') return 0;
        if (c == '+' || c == '-') return 1;
        if (c >= '0' && c <= '9') return 2;
        return 3;
    }
public:
    int myAtoi(string s) {
        int state = 0, sign = 1;
        long long value = 0;
        for (char c : s) {
            state = table[state][kind(c)];                     // look up the next state
            if (state == 1) {
                sign = (c == '-') ? -1 : 1;                    // we just read the sign
            } else if (state == 2) {
                value = value * 10 + (c - '0');                // add one more digit
                if (value > (long long)INT_MAX + 1) value = (long long)INT_MAX + 1;   // never let it grow beyond the limit
            } else if (state == 3) {
                break;                                         // end state: stop reading
            }
        }
        value *= sign;
        if (value > INT_MAX) return INT_MAX;                   // clamp to the 32-bit range
        if (value < INT_MIN) return INT_MIN;
        return (int)value;
    }
};

6 Approach 3: One Pass with a Check Before Each Digit (Most Optimized)

Most optimized

Idea: Walk once over the string with an index: skip spaces, read the sign, then add digits to a 32-bit result. Before adding a digit, check whether result * 10 + digit would pass 2147483647. If yes, return the maximum (or the minimum for a negative number) immediately.

A cashier who counts coins one by one and shouts 'full!' the moment the next coin would not fit in the till.
TimeSpaceGood sideWeak side
O(n)O(1)Uses only 32-bit numbers, one pass, no extra strings: the same memory as the simplest loop.The overflow check (the 7 at the end) is the part people forget.

Code

class Solution {
public:
    int myAtoi(string s) {
        int n = s.size(), i = 0;
        while (i < n && s[i] == ' ') i++;                      // skip leading spaces
        int sign = 1;
        if (i < n && (s[i] == '+' || s[i] == '-')) {           // optional sign
            sign = (s[i] == '-') ? -1 : 1;
            i++;
        }
        int result = 0;                                        // only 32-bit numbers are used
        while (i < n && s[i] >= '0' && s[i] <= '9') {          // read digits until something else shows up
            int digit = s[i] - '0';
            // would result * 10 + digit go above 2147483647 ?
            if (result > INT_MAX / 10 || (result == INT_MAX / 10 && digit > 7))
                return sign == 1 ? INT_MAX : INT_MIN;          // yes: return the limit right away
            result = result * 10 + digit;
            i++;
        }
        return sign * result;
    }
};

9 Common Mistakes

  • Skipping any whitespace (tabs, new lines): this problem only skips the space character.
  • Accepting a sign after digits or a second sign ("+-12" and "0-1" are 0).
  • Forgetting that "-2147483649" must give -2147483648: the clamp must work on the negative side too.
  • Checking the digit count instead of the value: "000000000000000000012" has many characters but is only 12.
  • Building the number in a 32-bit int without the pre-check: the multiplication already overflows before you compare.
  • Using a built-in isdigit that accepts non-ASCII digits (some languages do): compare with '0' and '9' instead.
