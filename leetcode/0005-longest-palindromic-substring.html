Given a string s, return the longest palindromic substring in s.

A palindrome reads the same forwards and backwards (like "aba"), and a substring is a continuous piece of the string. If several answers have the same longest length, any one of them is accepted.

2 💡 Examples and Constraints

Example 1

Input: s = "babad"
Output: "bab"
Explanation: "aba" is also a valid answer: both have length 3.

Example 2

Input: s = "cbbd"
Output: "bb"
Explanation: The longest palindrome is "bb".

📖 Example breakdown (Example 2), step by step
  • Every single letter is a palindrome, so the answer is at least 1 letter long.
  • Try every centre. Around the gap between the two bs the letters match (b = b), so "bb" (length 2) is a palindrome.
  • Growing it one more step compares c with d: they differ, so "bb" cannot grow.
  • No other centre gives anything longer than 1 letter, so the longest palindrome is "bb".
  • Result: "bb" ✅ (the expected output of Example 2)

⚠️ Constraints

  • 1 <= s.length <= 1000
  • s consists of only digits and English letters.

3 🧠 How to Think About It (in Easy Words)

Every palindrome has a centre: one letter (like the 'b' in 'aba') or the gap between two equal letters (like 'bb'). If you stand on a centre and walk outwards one step each side while the two letters match, you find the biggest palindrome around that centre. Try every centre and keep the longest.

Below you will find 4 approaches, from the simplest (brute force) to the best. Each one has the idea in plain words, its speed and memory cost, the code in C++, Java and Python (click the tabs; your choice is remembered), and a step-by-step dry run on a small input.

4 🚀 Approach 1: Brute Force: Check Every Substring

Brute force

💡 Intuition

List every substring, test each one to see if it is a palindrome, and keep the longest palindrome found.

Cut every strip out of the string and read each one forwards and backwards.

🪜 Algorithm, Step by Step

  1. Choose every start i and every end j.
  2. Skip substrings that are not longer than the best found so far.
  3. If s[i..j] reads the same backwards, remember it as the new best.
  4. Return the best substring.

⏱️ Complexity

CostWhy
TimeO(n³)About n²/2 substrings, each checked in O(n): O(n³).
SpaceO(1)C++ and Java compare the letters in place (O(1)); the Python version makes a temporary copy of each substring it checks.
Good sideWeak side
Simple to understand and verify.There are about n²/2 substrings and each check costs up to n steps.

💻 Code

class Solution {
public:
    string longestPalindrome(string s) {
        int n = s.size();
        int bestStart = 0, bestLen = 1;                 // any single letter is a palindrome
        for (int i = 0; i < n; i++) {                   // start of the substring
            for (int j = i; j < n; j++) {               // end of the substring (inclusive)
                if (isPalindrome(s, i, j) && j - i + 1 > bestLen) {
                    bestStart = i;                      // new longest palindrome found
                    bestLen = j - i + 1;
                }
            }
        }
        return s.substr(bestStart, bestLen);
    }
private:
    // compare letters from both ends moving inwards
    bool isPalindrome(const string& s, int left, int right) {
        while (left < right) {
            if (s[left] != s[right]) return false;
            left++;
            right--;
        }
        return true;
    }
};

5 🚀 Approach 2: Expand Around Each Centre

Optimized

💡 Intuition

A palindrome mirrors around its centre. There are 2n - 1 centres: each letter, and each gap between two letters. From a centre, move one step left and one step right while the letters match. The longest expansion over all centres is the answer. No table and no extra memory are needed.

Stand on a spot and look at both sides like a mirror; keep walking outwards while both sides show the same letter.

🪜 Algorithm, Step by Step

  1. For each position c, expand around the letter (c, c) for odd lengths and around the gap (c, c + 1) for even lengths.
  2. Expanding: while both ends are inside the string and their letters are equal, step one left and one right.
  3. The palindrome length is right - left - 1; keep the longest one and where it starts.

⏱️ Complexity

CostWhy
TimeO(n²)2n − 1 centres, each expanding at most about n/2 steps: O(n²).
SpaceO(1)Only a few indexes.
Good sideWeak side
Short, fast in practice and uses no extra memory: the favourite interview answer.Worst case (like 'aaaa...a') is still quadratic.

💻 Code

class Solution {
public:
    string longestPalindrome(string s) {
        int n = s.size();
        int bestStart = 0, bestLen = 1;
        for (int centre = 0; centre < n; centre++) {
            int odd = expand(s, centre, centre);        // centre is a letter: odd length, like "aba"
            int even = expand(s, centre, centre + 1);   // centre is a gap: even length, like "abba"
            int len = max(odd, even);
            if (len > bestLen) {
                bestLen = len;
                bestStart = centre - (len - 1) / 2;     // work out where this palindrome starts
            }
        }
        return s.substr(bestStart, bestLen);
    }
private:
    // grow outwards from (left, right) while the two letters match; return the palindrome length
    int expand(const string& s, int left, int right) {
        while (left >= 0 && right < (int)s.size() && s[left] == s[right]) {
            left--;
            right++;
        }
        return right - left - 1;                        // the loop went one step too far on each side
    }
};

class Solution:
    def longestPalindrome(self, s: str) -> str:
        n = len(s)
        best_start, best_len = 0, 1

        # grow outwards from (left, right) while the two letters match; return the palindrome length
        def expand(left: int, right: int) -> int:
            while left >= 0 and right < n and s[left] == s[right]:
                left -= 1
                right += 1
            return right - left - 1                     # the loop went one step too far on each side

        for centre in range(n):
            odd = expand(centre, centre)                # centre is a letter: odd length, like "aba"
            even = expand(centre, centre + 1)           # centre is a gap: even length, like "abba"
            length = max(odd, even)
            if length > best_len:
                best_len = length
                best_start = centre - (length - 1) // 2     # work out where this palindrome starts
        return s[best_start:best_start + best_len]

6 🚀 Approach 3: Dynamic Programming Table

Optimized (table)

💡 Intuition

Let dp[i][j] be true if s[i..j] is a palindrome. A substring is a palindrome when its two end letters match and the inside part is a palindrome (or the inside is empty or a single letter). We fill the table from short substrings to long ones, so the inside is always already known.

Keep a notebook of every smaller palindrome answer so that a bigger one only needs one look-up.

🪜 Algorithm, Step by Step

  1. Mark dp[i][i] = true for every i (one letter).
  2. For lengths 2 to n, for each start i (end j = i + length - 1): dp[i][j] = (s[i] == s[j]) and (length == 2 or dp[i+1][j-1]).
  3. Whenever dp[i][j] is true and longer than the best, remember it.

⏱️ Complexity

CostWhy
TimeO(n²)n² cells, each filled in O(1).
SpaceO(n²)The n × n table of true/false values.
Good sideWeak side
Good to learn the dynamic-programming idea.Uses an n x n table: more memory than expanding around centres.

💻 Code

class Solution {
public:
    string longestPalindrome(string s) {
        int n = s.size();
        vector<vector<bool>> dp(n, vector<bool>(n, false));   // dp[i][j]: is s[i..j] a palindrome?
        int bestStart = 0, bestLen = 1;
        for (int i = 0; i < n; i++) dp[i][i] = true;          // every single letter is a palindrome
        for (int len = 2; len <= n; len++) {                  // substring length: short first, then longer
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;                          // end of the substring
                if (s[i] == s[j] && (len == 2 || dp[i + 1][j - 1])) {   // ends match AND the inside is a palindrome
                    dp[i][j] = true;
                    if (len > bestLen) {
                        bestStart = i;
                        bestLen = len;
                    }
                }
            }
        }
        return s.substr(bestStart, bestLen);
    }
};

class Solution:
    def longestPalindrome(self, s: str) -> str:
        n = len(s)
        dp = [[False] * n for _ in range(n)]            # dp[i][j]: is s[i..j] a palindrome?
        best_start, best_len = 0, 1
        for i in range(n):
            dp[i][i] = True                             # every single letter is a palindrome
        for length in range(2, n + 1):                  # substring length: short first, then longer
            for i in range(n - length + 1):
                j = i + length - 1                      # end of the substring
                if s[i] == s[j] and (length == 2 or dp[i + 1][j - 1]):   # ends match AND the inside is a palindrome
                    dp[i][j] = True
                    if length > best_len:
                        best_start, best_len = i, length
        return s[best_start:best_start + best_len]

7 🚀 Approach 4: Manacher's Algorithm (Most Optimized)

Most optimized

💡 Intuition

Put a # between every letter (and at both ends) so every palindrome has odd length and a single centre: "abba" becomes "#a#b#b#a#". Keep, for every position, the radius of the palindrome centred there. While scanning, remember the palindrome that reaches furthest to the right (centre c, right edge r). A new position inside it can reuse the answer of its mirror position, so we only expand when we run past r. Every expansion moves r forward, so the total work is linear.

If you have already measured a mirror image of a spot, you do not measure it again from scratch; you copy that result and only check the new part.

🪜 Algorithm, Step by Step

  1. Build t = "#" + "#".join(s) + "#" so every palindrome has odd length and one centre.
  2. Keep radius[i] for every position, plus the centre and right edge of the palindrome that reaches furthest right.
  3. For a position inside that palindrome, start from its mirror's radius (never past right).
  4. Expand while the characters on both sides match; if the new palindrome passes right, it becomes the new (centre, right).
  5. Track the biggest radius; the answer starts at (best_centre - best_radius) / 2 in s and has length best_radius.

⏱️ Complexity

CostWhy
TimeO(n)Every successful expansion pushes the right edge forward, and the right edge never moves back, so the total work is O(n).
SpaceO(n)The transformed string and the radius array, each about 2n + 1 long.
Good sideWeak side
The only linear-time solution; great to know, rarely required in interviews.Harder to explain and to remember than expanding around centres.

💻 Code

class Solution {
public:
    string longestPalindrome(string s) {
        // t = "#a#b#a#" : the # signs make every palindrome odd-length with a real centre
        string t = "#";
        for (char ch : s) { t += ch; t += '#'; }
        int n = t.size();
        vector<int> radius(n, 0);                       // radius[i]: how far the palindrome centred at i reaches
        int centre = 0, right = 0;                      // the palindrome that reaches furthest to the right
        int bestCentre = 0, bestRadius = 0;
        for (int i = 0; i < n; i++) {
            if (i < right) {
                // reuse the answer of the mirror position (2*centre - i), but never beyond 'right'
                radius[i] = min(right - i, radius[2 * centre - i]);
            }
            // try to expand beyond what we already know
            while (i - radius[i] - 1 >= 0 && i + radius[i] + 1 < n && t[i - radius[i] - 1] == t[i + radius[i] + 1]) {
                radius[i]++;
            }
            if (i + radius[i] > right) {                // this palindrome reaches further right: remember it
                centre = i;
                right = i + radius[i];
            }
            if (radius[i] > bestRadius) {
                bestRadius = radius[i];
                bestCentre = i;
            }
        }
        int start = (bestCentre - bestRadius) / 2;      // convert the position in t back to a position in s
        return s.substr(start, bestRadius);             // radius in t equals the palindrome length in s
    }
};
class Solution {
    public String longestPalindrome(String s) {
        // t = "#a#b#a#" : the # signs make every palindrome odd-length with a real centre
        StringBuilder sb = new StringBuilder("#");
        for (char ch : s.toCharArray()) { sb.append(ch).append('#'); }
        String t = sb.toString();
        int n = t.length();
        int[] radius = new int[n];                      // radius[i]: how far the palindrome centred at i reaches
        int centre = 0, right = 0;                      // the palindrome that reaches furthest to the right
        int bestCentre = 0, bestRadius = 0;
        for (int i = 0; i < n; i++) {
            if (i < right) {
                // reuse the answer of the mirror position (2*centre - i), but never beyond 'right'
                radius[i] = Math.min(right - i, radius[2 * centre - i]);
            }
            // try to expand beyond what we already know
            while (i - radius[i] - 1 >= 0 && i + radius[i] + 1 < n && t.charAt(i - radius[i] - 1) == t.charAt(i + radius[i] + 1)) {
                radius[i]++;
            }
            if (i + radius[i] > right) {                // this palindrome reaches further right: remember it
                centre = i;
                right = i + radius[i];
            }
            if (radius[i] > bestRadius) {
                bestRadius = radius[i];
                bestCentre = i;
            }
        }
        int start = (bestCentre - bestRadius) / 2;      // convert the position in t back to a position in s
        return s.substring(start, start + bestRadius);  // radius in t equals the palindrome length in s
    }
}
class Solution:
    def longestPalindrome(self, s: str) -> str:
        # t = "#a#b#a#" : the # signs make every palindrome odd-length with a real centre
        t = "#" + "#".join(s) + "#"
        n = len(t)
        radius = [0] * n                                # radius[i]: how far the palindrome centred at i reaches
        centre = right = 0                              # the palindrome that reaches furthest to the right
        best_centre = best_radius = 0
        for i in range(n):
            if i < right:
                # reuse the answer of the mirror position (2*centre - i), but never beyond 'right'
                radius[i] = min(right - i, radius[2 * centre - i])
            # try to expand beyond what we already know
            while i - radius[i] - 1 >= 0 and i + radius[i] + 1 < n and t[i - radius[i] - 1] == t[i + radius[i] + 1]:
                radius[i] += 1
            if i + radius[i] > right:                   # this palindrome reaches further right: remember it
                centre, right = i, i + radius[i]
            if radius[i] > best_radius:
                best_radius, best_centre = radius[i], i
        start = (best_centre - best_radius) // 2        # convert the position in t back to a position in s
        return s[start:start + best_radius]             # radius in t equals the palindrome length in s

9 🔑 Key Insights

  • Every palindrome has a centre: a letter (odd length) or a gap between two letters (even length): 2n − 1 centres in total.
  • Expanding around centres is the usual interview answer: O(n²) time, O(1) space and short code.
  • Manacher's algorithm reuses the mirror's answer inside a known palindrome to reach O(n); good to know, rarely required in interviews.
  • When there are ties ("bab" and "aba"), any one of them is accepted.

11 ⚠️ Common Mistakes

  • Only checking odd-length centres and missing even palindromes like "bb".
  • Returning the length instead of the substring (or the reverse).
  • Off-by-one when computing the start index from the centre and the length.
  • Mixing up substring with subsequence.
  • In the DP table, filling it in the wrong order (the inside dp[i+1][j-1] must already be known: go from short to long).
