Easy   Topics: String, Trie

You are given an array of strings strs. Find the longest common prefix: the longest string that every word in the array starts with. If the words have nothing in common at the start, return the empty string "".

2 💡 Examples and Constraints

Example 1

Input: strs = ["flower","flow","flight"]
Output: "fl"
Explanation: All three words start with "fl". The next letters are "o", "o" and "i", which differ, so the prefix stops there.

Example 2

Input: strs = ["dog","racecar","car"]
Output: ""
Explanation: The words do not even share their first letter, so the common prefix is empty.

📖 Example breakdown (Example 1), step by step
  • The words are flower, flow and flight.
  • Column 0: all three words have f. Column 1: all three have l.
  • Column 2: flower has o, flow has o, but flight has i: they disagree, so we stop before column 2.
  • Everything before column 2 is shared: the prefix is the first two letters, fl.
  • Result: "fl" ✅ (the expected output of Example 1)

⚠️ Constraints

  • 1 <= strs.length <= 200
  • 0 <= strs[i].length <= 200
  • strs[i] consists of lowercase English letters if it is non-empty.

3 🧠 How to Think About It (in Easy Words)

Imagine lining the words up one under the other and drawing a vertical line down the left side. How far to the right can you move the line before two words disagree? You can check column by column (all words, first letter; all words, second letter ...). Or you can keep a guess for the prefix and shorten it whenever a word does not start with it. A third trick: after sorting the words, only the first and the last can differ the most, so comparing just those two is enough.

Below you will find 3 approaches, from the simplest (brute force) to the best. Each one has the idea in plain words, its speed and memory cost, the code in C++, Java and Python (click the tabs; your choice is remembered), and a step-by-step dry run on a small input.

4 🚀 Approach 1: Vertical Scanning: Compare Column by Column

Optimized

💡 Intuition

Take the first word as the model. For position 0, 1, 2 ... check that every other word has the same letter at that position. The moment one word is too short or has a different letter, the answer is the first word up to (not including) that position.

Slide a ruler down the first letters of all words, then the second letters, and stop at the first column where someone disagrees.

🪜 Algorithm, Step by Step

  1. Take the first word as the model.
  2. For column 0, 1, 2, ... compare its letter with the same column in every other word.
  3. If a word is too short or has a different letter, return the first word up to (not including) that column.
  4. If the loop ends, the whole first word is the answer.

⏱️ Complexity

CostWhy
TimeO(S), S = total number of letters in all wordseach column check looks at one letter per word, and we never look at more letters than the words contain: O(S) letters in total
SpaceO(1)only a few variables; the answer is a slice of the first word
Good sideWeak side
Stops as early as possible and never builds an extra string.The two nested loops need care (a word can be shorter than the first word).

💻 Code

class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        for (size_t i = 0; i < strs[0].size(); i++) {
            char c = strs[0][i];                               // the letter every other word must have in column i
            for (size_t k = 1; k < strs.size(); k++) {
                if (i >= strs[k].size() || strs[k][i] != c)    // word k is too short or disagrees
                    return strs[0].substr(0, i);
            }
        }
        return strs[0];                                        // the whole first word is shared by everyone
    }
};

5 🚀 Approach 2: Horizontal Scanning: Shrink a Guess Word by Word

Optimized

💡 Intuition

Start with the whole first word as the guess. For every next word, cut letters off the end of the guess until the word starts with the guess. If the guess becomes empty, stop: there is no common prefix.

You hold a ruler as long as the first word and keep sawing it shorter until it fits the start of every word.

🪜 Algorithm, Step by Step

  1. Let the guess be the whole first word.
  2. For every other word, while the word does not start with the guess, cut the last letter off the guess.
  3. If the guess becomes empty, return the empty string.
  4. After the last word return the guess.

⏱️ Complexity

CostWhy
TimeO(S)every letter of the guess is cut once and every comparison looks at most at the guess length per word: O(S) in total
SpaceO(1)only the guess string, which is at most the first word
Good sideWeak side
Easy to explain and the loop over words is simple.Can do extra work: the guess is shortened one letter at a time and re-checked.

💻 Code

class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        string prefix = strs[0];
        for (size_t k = 1; k < strs.size(); k++) {
            while (strs[k].compare(0, prefix.size(), prefix) != 0) {   // does word k start with the guess?
                prefix.pop_back();                                      // no: make the guess one letter shorter
                if (prefix.empty()) return "";
            }
        }
        return prefix;
    }
};
class Solution {
    public String longestCommonPrefix(String[] strs) {
        String prefix = strs[0];
        for (int k = 1; k < strs.length; k++) {
            while (!strs[k].startsWith(prefix)) {              // does word k start with the guess?
                prefix = prefix.substring(0, prefix.length() - 1);   // no: make the guess one letter shorter
                if (prefix.isEmpty()) return "";
            }
        }
        return prefix;
    }
}
class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        prefix = strs[0]
        for word in strs[1:]:
            while not word.startswith(prefix):          # does this word start with the guess?
                prefix = prefix[:-1]                    # no: make the guess one letter shorter
                if not prefix:
                    return ""
        return prefix

6 🚀 Approach 3: Sort, Then Compare Only the First and the Last Word

Most optimized (shortest code)

💡 Intuition

After sorting the words alphabetically, the first and the last word are the two most different ones. Whatever those two share at the start, every word in between shares as well. So compare just those two letter by letter.

In a phone book the first and last names are the farthest apart: if they begin the same way, everything between them does too.

🪜 Algorithm, Step by Step

  1. Sort the words alphabetically.
  2. Take the first and the last word of the sorted list.
  3. Walk along both words while their letters are equal and neither word has ended.
  4. Return that many letters of the first word.

⏱️ Complexity

CostWhy
TimeO(S log n) for the sortsorting n words costs O(n log n) comparisons, each looking at up to the word length
SpaceO(1) extra (the sort may use some memory)sorting may use extra memory; the comparison itself needs none
Good sideWeak side
Very short, and the idea is neat.The sort costs more than the scanning methods, and it changes the input array.

💻 Code

class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        sort(strs.begin(), strs.end());
        const string& first = strs.front();
        const string& last = strs.back();
        size_t i = 0;
        while (i < first.size() && i < last.size() && first[i] == last[i]) i++;   // how far do the two extremes agree?
        return first.substr(0, i);
    }
};
class Solution {
    public String longestCommonPrefix(String[] strs) {
        Arrays.sort(strs);
        String first = strs[0], last = strs[strs.length - 1];
        int i = 0;
        while (i < first.length() && i < last.length() && first.charAt(i) == last.charAt(i)) i++;   // how far do the two extremes agree?
        return first.substring(0, i);
    }
}
class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        strs.sort()
        first, last = strs[0], strs[-1]
        i = 0
        while i < len(first) and i < len(last) and first[i] == last[i]:   # how far do the two extremes agree?
            i += 1
        return first[:i]

8 🔑 Key Insights

  • The answer can never be longer than the shortest word, and an empty word makes the answer empty.
  • After sorting, the first and last words are the two most different ones, so whatever they share is shared by every word in between. On the example the sorted first word is flight and the last is flower: they share fl.
  • Vertical scanning stops at the very first disagreement, so it is usually the quickest in practice.
  • The same idea works with a trie (prefix tree): the common prefix is the path from the root until the first branching or word end.

10 ⚠️ Common Mistakes

  • Forgetting that a word can be shorter than the first word: check the length before reading a letter at position i.
  • Returning the whole first word too early: it is only the answer if every word starts with it.
  • Not handling empty strings in the array: the answer is then always the empty string.
  • Comparing the first and last word without sorting first: the trick only works for the sorted order.
  • Mixing up a prefix with a common substring: the shared part must be at the very beginning of every word.
