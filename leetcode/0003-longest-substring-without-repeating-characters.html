Given a string s, find the length of the longest substring that contains no repeated characters.

A substring is a continuous piece of the string (no skipping characters).

2 Examples and Constraints

Example 1

Input: s = "abcabcbb"
Output: 3
Explanation: The longest substring without repeating characters is "abc", so the length is 3.

Example 2

Input: s = "bbbbb"
Output: 1
Explanation: Every character is "b", so the longest valid substring is "b", with length 1.

Example 3

Input: s = "pwwkew"
Output: 3
Explanation: The answer is "wke", with length 3. Note that the answer must be a substring: "pwke" is a subsequence (it skips a letter), not a substring.

Constraints

  • 0 <= s.length <= 5 * 104
  • s consists of English letters, digits, symbols and spaces.

3 How to Think About It (in Easy Words)

Imagine a caterpillar crawling along the string with a head (right end) and a tail (left end). The head moves forward eating one new letter at a time. If the letter was already inside the caterpillar, the tail must move forward until the duplicate is gone. The longest the caterpillar ever gets is the answer.

Below you will find 4 approaches, from the simplest (brute force) to the best. Each one has the idea in plain words, its speed and memory cost, the code in C++, Java and Python (click the tabs; your choice is remembered), and a step-by-step dry run on a small input.

4 Approach 1: Brute Force: Check Every Substring

Brute force

Idea: Look at every possible substring (every start and every end). For each one, check whether all its letters are different. Keep the longest valid length.

Cut out every possible strip of the string and test each strip for repeated letters.
TimeSpaceGood sideWeak side
O(n³)O(min(n, alphabet))Obviously correct.Far too slow for long strings (50,000 characters would take about 1013 steps).

Code

class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int n = s.size(), best = 0;
        for (int i = 0; i < n; i++) {                   // start of the substring
            for (int j = i; j < n; j++) {               // end of the substring (inclusive)
                if (allUnique(s, i, j)) {
                    best = max(best, j - i + 1);        // valid: remember the longest
                }
            }
        }
        return best;
    }
private:
    // true if all characters in s[i..j] are different
    bool allUnique(const string& s, int i, int j) {
        unordered_set<char> seen;
        for (int k = i; k <= j; k++) {
            if (seen.count(s[k])) return false;         // seen before: a repeat
            seen.insert(s[k]);
        }
        return true;
    }
};

    private boolean allUnique(String s, int i, int j) {
        Set<Character> seen = new HashSet<>();
        for (int k = i; k <= j; k++) {
            if (!seen.add(s.charAt(k))) return false;   // add() is false when it was already there: a repeat
        }
        return true;
    }
}

5 Approach 2: Better Brute Force: Grow From Each Start Until a Repeat

Optimized (still quadratic)

Idea: For each starting position, keep adding the next letter to a set. The moment a letter is already in the set, stop: no longer substring from this start can be valid. This avoids re-checking the same letters again and again.

Start walking from each house; stop as soon as you pass a colour you have already seen.
TimeSpaceGood sideWeak side
O(n²)O(min(n, alphabet))Simple and much faster than checking every substring.Still restarts from scratch for every start position.

Code

class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int n = s.size(), best = 0;
        for (int i = 0; i < n; i++) {                   // try every start position
            unordered_set<char> seen;
            for (int j = i; j < n; j++) {               // grow to the right
                if (seen.count(s[j])) break;            // repeat found: stop growing from this start
                seen.insert(s[j]);
                best = max(best, j - i + 1);
            }
        }
        return best;
    }
};

6 Approach 3: Sliding Window With a Set

Optimized (linear)

Idea: Keep a window [left, right] that never contains a repeat, plus a set of the letters inside it. Move right forward. If the new letter is already in the window, move left forward (removing letters) until the duplicate is gone. Then add the new letter and record the window size. Each letter enters and leaves the window at most once.

The caterpillar: the head eats forward, the tail shrinks only when needed.
TimeSpaceGood sideWeak side
O(n)O(min(n, alphabet))Linear time and a classic technique (sliding window).The tail may move one step at a time, so up to 2n steps in total.

Code

class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        unordered_set<char> window;                     // letters currently inside the window
        int left = 0, best = 0;
        for (int right = 0; right < (int)s.size(); right++) {
            while (window.count(s[right])) {            // new letter already inside? shrink from the left
                window.erase(s[left]);
                left++;
            }
            window.insert(s[right]);                    // now the new letter can safely join
            best = max(best, right - left + 1);         // window size = right - left + 1
        }
        return best;
    }
};
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Set<Character> window = new HashSet<>();        // letters currently inside the window
        int left = 0, best = 0;
        for (int right = 0; right < s.length(); right++) {
            while (window.contains(s.charAt(right))) {  // new letter already inside? shrink from the left
                window.remove(s.charAt(left));
                left++;
            }
            window.add(s.charAt(right));                // now the new letter can safely join
            best = Math.max(best, right - left + 1);    // window size = right - left + 1
        }
        return best;
    }
}
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:

7 Approach 4: Sliding Window With 'Last Seen' Positions (Most Optimized)

Most optimized

Idea: Instead of moving the left end one step at a time, remember the last position where each character appeared. When the right end meets a character that was last seen inside the current window, jump left straight to one place after that old position. Every character is visited exactly once, so it is a single clean pass.

The caterpillar has a notebook with the last spot of every leaf; when it sees a repeated leaf, its tail teleports to just past the old copy.
TimeSpaceGood sideWeak side
O(n)O(1) (a fixed table of 256 characters; or O(min(n, alphabet)) with a map)One pass, constant memory for ASCII, fastest in practice.The jump must never move left backwards (use max).

Code

class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        vector<int> last(256, -1);                      // last[c] = last index where character c appeared
        int left = 0, best = 0;                         // window is s[left..right]
        for (int right = 0; right < (int)s.size(); right++) {
            unsigned char c = s[right];
            if (last[c] >= left) {                      // c already inside the window?
                left = last[c] + 1;                     // jump left to just after the old copy
            }
            last[c] = right;                            // remember the newest position of c
            best = max(best, right - left + 1);
        }
        return best;
    }
};
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int[] last = new int[256];                      // last[c] = (last index of c) + 1; 0 means 'never seen'
        int left = 0, best = 0;                         // window is s[left..right]
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            left = Math.max(left, last[c]);             // jump left to just after the old copy (never backwards)
            last[c] = right + 1;                        // remember the newest position of c (shifted by 1)
            best = Math.max(best, right - left + 1);
        }
        return best;
    }
}
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last = {}                                       # last[c] = last index where character c appeared
        left, best = 0, 0                               # window is s[left..right]
        for right, c in enumerate(s):
            if c in last and last[c] >= left:           # c already inside the window?
                left = last[c] + 1                      # jump left to just after the old copy
            last[c] = right                             # remember the newest position of c
            best = max(best, right - left + 1)
        return best

10 Common Mistakes

  • Confusing a substring (continuous) with a subsequence (may skip letters): "pwke" is not valid for "pwwkew".
  • In the 'last seen' method, moving left backwards when the old copy is outside the window: always take the larger value.
  • Forgetting the empty string (length 0): the answer is 0.
  • Returning the substring instead of its length.
  • Using an array of 26 letters: the input can contain digits, symbols and spaces.
