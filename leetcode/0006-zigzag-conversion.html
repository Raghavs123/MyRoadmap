Medium   Topics: String

You are given a string s and a number of rows numRows. Write the letters of s in a zigzag (snake) shape: start at the top row, go down one row for each letter until you reach the bottom row, then go up diagonally one row for each letter until you are back at the top, then go down again, and so on.

After all letters are placed, read the picture row by row, from the top row to the bottom row and from left to right inside a row, and join the letters into one new string. Return that string.

2 Examples and Constraints

Example 1

Input: s = "PAYPALISHIRING", numRows = 3
Output: "PAHNAPLSIIGYIR"
Explanation: With 3 rows the letters land like this: row 0 has P A H N, row 1 has A P L S I I G, row 2 has Y I R. Reading the rows one after the other gives "PAHN" + "APLSIIG" + "YIR".

Example 2

Input: s = "PAYPALISHIRING", numRows = 4
Output: "PINALSIGYAHRPI"
Explanation: With 4 rows: row 0 has P I N, row 1 has A L S I G, row 2 has Y A H R, row 3 has P I.

Example 3

Input: s = "A", numRows = 1
Output: "A"
Explanation: There is only one letter and one row, so nothing changes.

Constraints

  • 1 <= s.length <= 1000
  • s consists of English letters (lower-case and upper-case), ',' and '.'.
  • 1 <= numRows <= 1000

3 How to Think About It (in Easy Words)

Imagine writing the letters on a fence made of numRows horizontal wires. You walk down the wires, then up, then down again, hanging one letter on each wire as you pass. At the end you collect the letters wire by wire. You do not really need the fence: you only need to know which wire each letter lands on. The wire number goes 0, 1, 2, ..., last, last-1, ..., 1, 0, 1, 2, ... again and again.

Below you will find 3 approaches, from the simplest (brute force) to the best. Each one has the idea in plain words, its speed and memory cost, the code in C++, Java and Python (click the tabs; your choice is remembered), and a step-by-step dry run on a small input.

4 Approach 1: Brute Force: Draw the Whole Zigzag in a Grid

Brute force

Idea: Make a table with numRows rows and enough columns. Walk through the string and put each letter into its cell: go down the column, then up the diagonal (one row up and one column to the right). When all letters are placed, read the table row by row and skip the empty cells.

Like drawing the zigzag on squared paper and then reading it line by line with your finger.
TimeSpaceGood sideWeak side
O(numRows × n)O(numRows × n)You really build the picture, so it is the easiest one to see and to trust.The table is mostly empty cells: it wastes memory and time when there are many rows.

Code

class Solution {
public:
    string convert(string s, int numRows) {
        int n = s.size();
        if (numRows == 1 || numRows >= n) return s;           // one row, or every letter gets its own row: nothing changes
        int cycle = 2 * numRows - 2;                           // letters in one full trip: down the column, then up the diagonal
        int numCols = (n / cycle + 1) * (numRows - 1);         // each trip uses (numRows - 1) columns
        vector<string> grid(numRows, string(numCols, ' '));    // ' ' marks an empty cell (the input never has spaces)
        int row = 0, col = 0;
        for (int i = 0; i < n; i++) {
            grid[row][col] = s[i];                             // drop the letter into its cell
            if (i % cycle < numRows - 1) {
                row++;                                         // still walking down the column
            } else {
                row--;                                         // walking up the diagonal: one row up ...
                col++;                                         // ... and one column to the right
            }
        }
        string answer;
        for (int r = 0; r < numRows; r++)                      // read the grid row by row
            for (int c = 0; c < numCols; c++)
                if (grid[r][c] != ' ') answer += grid[r][c];   // skip empty cells
        return answer;
    }
};

class Solution:
    def convert(self, s: str, numRows: int) -> str:
        n = len(s)
        if numRows == 1 or numRows >= n:
            return s                                    # one row, or every letter gets its own row: nothing changes
        cycle = 2 * numRows - 2                         # letters in one full trip: down the column, then up the diagonal
        num_cols = (n // cycle + 1) * (numRows - 1)     # each trip uses (numRows - 1) columns
        grid = [[" "] * num_cols for _ in range(numRows)]   # " " marks an empty cell (the input never has spaces)
        row = col = 0
        for i, ch in enumerate(s):
            grid[row][col] = ch                         # drop the letter into its cell
            if i % cycle < numRows - 1:
                row += 1                                # still walking down the column
            else:
                row -= 1                                # walking up the diagonal: one row up ...
                col += 1                                # ... and one column to the right
        # read the grid row by row, skipping empty cells
        return "".join(ch for line in grid for ch in line if ch != " ")

5 Approach 2: One String per Row (Bounce Up and Down)

Optimized

Idea: Keep one small string for every row. For each letter, add it to the string of the current row, then move to the next row. Walk down until the last row, turn around, walk up until row 0, turn around again. At the end, glue the row strings together.

Like dealing cards into numRows piles, going down the line of piles and then back up, again and again.
TimeSpaceGood sideWeak side
O(n)O(n)Very short, no empty cells, one pass over the string.Needs extra row strings (about n letters in total) before the final answer is built.

Code

class Solution {
public:
    string convert(string s, int numRows) {
        if (numRows == 1) return s;                            // a single row cannot zigzag
        vector<string> rows(numRows);                          // rows[r] collects the letters that land on row r
        int row = 0, step = 1;                                 // step = +1 while going down, -1 while going up
        for (char c : s) {
            rows[row] += c;                                    // put the letter on its row
            if (row == 0) step = 1;                            // reached the top: turn and go down
            else if (row == numRows - 1) step = -1;            // reached the bottom: turn and go up
            row += step;                                       // move to the next row
        }
        string answer;
        for (const string& r : rows) answer += r;              // glue the rows together, top to bottom
        return answer;
    }
};
class Solution {
    public String convert(String s, int numRows) {
        if (numRows == 1) return s;                            // a single row cannot zigzag
        StringBuilder[] rows = new StringBuilder[numRows];     // rows[r] collects the letters that land on row r
        for (int r = 0; r < numRows; r++) rows[r] = new StringBuilder();
        int row = 0, step = 1;                                 // step = +1 while going down, -1 while going up
        for (int i = 0; i < s.length(); i++) {
            rows[row].append(s.charAt(i));                     // put the letter on its row
            if (row == 0) step = 1;                            // reached the top: turn and go down
            else if (row == numRows - 1) step = -1;            // reached the bottom: turn and go up
            row += step;                                       // move to the next row
        }
        StringBuilder answer = new StringBuilder();
        for (StringBuilder r : rows) answer.append(r);         // glue the rows together, top to bottom
        return answer.toString();
    }
}

6 Approach 3: Jump by the Cycle Formula (Most Optimized)

Most optimized

Idea: The zigzag repeats every cycle = 2 * numRows - 2 letters. So row r always owns the letters at positions r, r + cycle, r + 2*cycle, ... (the vertical line). The middle rows also own one diagonal letter between two vertical ones, at position j + cycle - 2*r. Build the answer by visiting each row and jumping straight to those positions.

Like knowing a bus timetable: bus line r stops every cycle minutes, so you never need to ride along the whole route to find its stops.
TimeSpaceGood sideWeak side
O(n)O(1) extra (only the answer)No row strings and no grid: only the answer string is built.The jump formula is easy to get wrong by one, so you must check it on a small example.

Code

class Solution {
public:
    string convert(string s, int numRows) {
        int n = s.size();
        if (numRows == 1 || numRows >= n) return s;           // nothing to zigzag
        int cycle = 2 * numRows - 2;                           // the shape repeats every 'cycle' letters
        string answer;
        answer.reserve(n);
        for (int r = 0; r < numRows; r++) {                    // row by row, top to bottom
            for (int j = r; j < n; j += cycle) {               // the letters on the vertical line of this row
                answer += s[j];
                int k = j + cycle - 2 * r;                     // the diagonal letter right after s[j] ...
                if (r != 0 && r != numRows - 1 && k < n)       // ... exists only for the middle rows
                    answer += s[k];
            }
        }
        return answer;
    }
};

        n = len(s)

            return s                                    # nothing to zigzag

                    answer.append(s[k])
        return "".join(answer)

9 Common Mistakes

  • Forgetting the numRows == 1 case: the cycle length becomes 0, so a loop that jumps by cycle never ends (or divides by zero).
  • Turning around at the wrong moment: you must turn at row 0 and at the last row, and with numRows == 2 you turn after every single letter.
  • Adding the diagonal letter for the first and last rows too: only the middle rows have diagonal letters.
  • Not checking k < n before reading the diagonal letter, which reads past the end of the string.
  • Using a space as the 'empty cell' marker in the grid approach when spaces could be part of the input (here the constraints exclude spaces).
