Medium   Topics: Linked List, Math, Recursion

You are given the heads of two non-empty linked lists. Each list represents a non-negative whole number. The digits are stored in reverse order: the first node is the ones digit, the next node is the tens digit, and so on. Every node holds a single digit (0 to 9).

Add the two numbers and return the sum as a linked list in the same reversed-digit format.

You may assume that neither number has leading zeros, except for the number 0 itself.

2 Examples and Constraints

Example 1

Input: l1 = [2,4,3], l2 = [5,6,4]
Output: [7,0,8]
Explanation: 342 + 465 = 807, and 807 stored backwards is 7 → 0 → 8.

Example 2

Input: l1 = [0], l2 = [0]
Output: [0]
Explanation: 0 + 0 = 0.

Example 3

Input: l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
Output: [8,9,9,9,0,0,0,1]
Explanation: 9999999 + 9999 = 10009998, stored backwards as 8 → 9 → 9 → 9 → 0 → 0 → 0 → 1.

Constraints

  • The number of nodes in each list is in the range [1, 100].
  • 0 <= Node.val <= 9
  • It is guaranteed that the list represents a number that does not have leading zeros.

3 How to Think About It (in Easy Words)

Remember how you add on paper: start from the ones column, write the last digit of the column sum, and carry the rest to the next column. The lists already give you the digits starting from the ones column, so the paper method fits perfectly: walk both lists together, add the two digits and the carry, write one digit, keep the carry.

Below you will find 3 approaches, from the simplest (brute force) to the best. Each one has the idea in plain words, its speed and memory cost, the code in C++, Java and Python (click the tabs; your choice is remembered), and a step-by-step dry run on a small input.

4 Approach 1: Copy the Digits Into Arrays, Add, Rebuild

Brute force

Idea: First read all digits of each list into two arrays. Then add the arrays column by column with a carry (just like paper addition). Finally build a brand-new linked list from the answer digits. It is easy to follow but uses extra arrays.

Copy both numbers onto scrap paper, add them there, then write the answer onto a new chain of cards.
TimeSpaceGood sideWeak side
O(max(m, n))O(m + n)Each step is simple and can be checked separately.Extra memory for two arrays and a result array before building the list.

Code

class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        vector<int> a, b, sum;                      // digits of the two numbers and of the answer
        for (ListNode* p = l1; p != nullptr; p = p->next) a.push_back(p->val);
        for (ListNode* p = l2; p != nullptr; p = p->next) b.push_back(p->val);

        int carry = 0;
        size_t n = max(a.size(), b.size());
        for (size_t i = 0; i < n; i++) {            // add column by column, ones digit first
            int x = i < a.size() ? a[i] : 0;        // a shorter number counts as 0 in missing columns
            int y = i < b.size() ? b[i] : 0;
            int total = x + y + carry;
            sum.push_back(total % 10);              // the digit we write down
            carry = total / 10;                     // the digit we carry
        }
        if (carry > 0) sum.push_back(carry);        // a final carry adds one more column

        ListNode dummy;                             // a fake head makes appending easy
        ListNode* tail = &dummy;
        for (int d : sum) {
            tail->next = new ListNode(d);
            tail = tail->next;
        }
        return dummy.next;
    }
};

5 Approach 2: Recursion: Add One Column, Ask Recursion for the Rest

Optimized (elegant)

Idea: Write a helper that adds one column (two digits plus the carry), creates one node for it, and then asks itself to handle the rest of both lists with the new carry. It stops when both lists and the carry are all empty.

Dominoes: the first column's work triggers the next, and the next, until nothing is left.
TimeSpaceGood sideWeak side
O(max(m, n))O(max(m, n)) for the recursion stackVery short, matches the idea of 'one column then the rest'.Uses the call stack (fine here because there are at most 100 nodes).

Code

class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        return add(l1, l2, 0);
    }
private:
    // add the current column of l1, l2 and 'carry', then recurse on the rest
    ListNode* add(ListNode* l1, ListNode* l2, int carry) {
        if (l1 == nullptr && l2 == nullptr && carry == 0) {
            return nullptr;                         // nothing left to add: end of the answer list
        }
        int total = carry;
        if (l1 != nullptr) total += l1->val;
        if (l2 != nullptr) total += l2->val;
        ListNode* node = new ListNode(total % 10);  // the digit for this column
        node->next = add(l1 ? l1->next : nullptr,   // move both lists one step
                         l2 ? l2->next : nullptr,
                         total / 10);               // pass the carry along
        return node;
    }
};

class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        # add the current column of l1, l2 and 'carry', then recurse on the rest
        def add(a, b, carry):
            if a is None and b is None and carry == 0:
                return None                         # nothing left to add: end of the answer list
            total = carry
            if a:
                total += a.val
            if b:
                total += b.val
            node = ListNode(total % 10)             # the digit for this column
            node.next = add(a.next if a else None,  # move both lists one step
                            b.next if b else None,
                            total // 10)            # pass the carry along
            return node

        return add(l1, l2, 0)

6 Approach 3: Iterative Walk With a Dummy Head (Most Optimized)

Most optimized

Idea: Walk down both lists together with a loop. At each step add the two digits (use 0 if a list has ended) and the carry, append one new node with the last digit, and keep the carry for the next step. A dummy head node means we never need a special case for the first node. We stop when both lists are finished and no carry is left.

Paper addition done exactly as taught in school, one column at a time, writing the answer on a new strip of paper.
TimeSpaceGood sideWeak side
O(max(m, n))O(1) extra (the answer list itself is required output)One pass, no extra arrays, no recursion; the standard interview answer.You must remember the final carry (for example 5 + 5 = 10 needs a second node).

Code

class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        ListNode dummy;                             // fake head: the real answer starts at dummy.next
        ListNode* tail = &dummy;                    // where the next digit will be attached
        int carry = 0;
        while (l1 != nullptr || l2 != nullptr || carry != 0) {
            int total = carry;                      // start with the carry from the previous column
            if (l1 != nullptr) { total += l1->val; l1 = l1->next; }   // add digit of first number
            if (l2 != nullptr) { total += l2->val; l2 = l2->next; }   // add digit of second number
            tail->next = new ListNode(total % 10);  // write the ones digit of this column
            tail = tail->next;
            carry = total / 10;                     // 0 or 1: carry to the next column
        }
        return dummy.next;
    }
};

class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0)                         # fake head: the real answer starts at dummy.next
        tail = dummy                                # where the next digit will be attached
        carry = 0
        while l1 or l2 or carry:
            total = carry                           # start with the carry from the previous column
            if l1:
                total += l1.val                     # add digit of first number
                l1 = l1.next
            if l2:
                total += l2.val                     # add digit of second number
                l2 = l2.next
            tail.next = ListNode(total % 10)        # write the ones digit of this column
            tail = tail.next
            carry = total // 10                     # 0 or 1: carry to the next column
        return dummy.next

9 Common Mistakes

  • Forgetting the final carry: 5 + 5 = 10 must produce two nodes, 0 → 1.
  • Stopping when the shorter list ends: the longer list's remaining digits (plus the carry) still have to be added.
  • Writing total / 10 instead of total % 10 as the digit (or the reverse).
  • Not using a dummy head and then crashing on the first node.
  • Trying to convert the lists to a normal integer: with up to 100 digits it overflows 32/64-bit integers in C++ and Java.
